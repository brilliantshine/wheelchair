## Flow

A test allocates a directory, populates fixtures and sometimes starts services or commands, then closes those processes. Most Node allocations are not removed; shell fixture suites remove their enclosing directory on shell EXIT. The viewer helper instead sweeps old repository-local scratch on a later allocation (`machine/test/service.test.js:16`, `machine/test/service.test.js:58`, `viewer/test/helpers/server.js:26`, `viewer/test/helpers/server.js:46`, `install/test/run.sh:8`).

```text
suite -> allocate directory -> fixtures and processes -> stop processes -> directory remains
                                                                    -> shell EXIT removes fixture
later viewer allocation -> sweep old viewer scratch
```

## Shell suites, paths, and failure boundaries

- `install/test/run.sh:8`, `codex/test/run.sh:8`, `sensitivity/test/run.sh:7`, `seen/test/hook_test.sh:5`, `seen/test/wording_test.sh:5`, `seen/test/set_test.sh:7` each create one `mktemp -d` root with the implementation's default `tmp.` prefix and install an EXIT trap removing it. Codex also makes `case.XXXXXX` children inside its root (`codex/test/run.sh:19`); sensitivity's temporary edit file is likewise inside its fixture (`sensitivity/test/run.sh:110`). `seen/test/run.sh:8` runs three independent fixture shells. EXIT normally handles successful and ordinary failed shell exits; it is not an explicit INT/TERM handler, so signal delivery to a shell waiting on children, forced process termination, and timeout escalation do not guarantee cleanup or child termination. The interval between allocation and trap registration also exists. No stale sweep is present in these scripts.
- Node `os.tmpdir()` and default `mktemp` consult the environment's temp-directory selection, including `TMPDIR`; the probe explicitly does (`machine/test/aside-probe.sh:7`). Viewer `makeDir` instead fixes the root in the checkout (`viewer/test/helpers/server.js:13`). Hard-coded `/tmp` strings appear as fake worktree/project values and assertions, for example `viewer/test/helpers/app-machine.js:184`, `viewer/test/helpers/app.js:57`, `viewer/test/app-threads.spec.js:158`; these are not allocations but changing their values can affect assertions. The standalone probe defaults to `/tmp` (`machine/test/aside-probe.sh:7`).
- On successful tests and ordinary assertion failures/throws, roots without removal remain; finally and test hooks can close processes, but do not remove those roots. Abrupt SIGINT/SIGTERM or timeout killing a Node/Playwright worker can bypass JavaScript teardown; no inspected harness installs a general signal cleanup. Playwright hooks may run on ordinary failures and runner-managed timeouts, but that is not a guarantee after forced termination (`viewer/test/app-doc.spec.js:38`, `viewer/test/app-doc.spec.js:39`).

Not looked at: product-internal temporary files created indirectly by code under test or external tools; operating system and runner implementation details beyond the checked harness code; actual historical directory contents or runtime counts. No tests were run.
