# T6 report — server line checker fixes

## Changes

- `machine/lib/server-lines.js`: the first escaped string allocation is sized to that string's closing quote; the simple escape lookup is module scoped. Detection allocates its 1 MiB batch only when an escaped run is copied. Outcome 2 now rejects a match anywhere in the complete top-level `jsonrpc`, `id`, or `method` member value.
- `machine/test/server-lines.test.js`: added coverage for a key nested in an object-valued `id` and for 300,000 short escaped strings in an 8,288,936-byte reply.

The large-line case took 10,870 ms before the fix and 548 ms after it. The nested-id reproduction returned a redacted line before the fix; after the fix it is held back with the expected stderr note.
