# R1 — fast escape-heavy JSON string decoding

## Changes

- `machine/lib/server-lines.js`: replaced per-escape Buffer creation and string/regex hex parsing with direct decoded-buffer writes, byte-based hex parsing, and manual UTF-8 encoding. Lone surrogates encode as U+FFFD.
- `machine/test/server-lines.test.js`: added byte-equality coverage for UTF-8, surrogate pairs, lone surrogates, simple escapes, and mixed runs.
