# T4 — launcher detection integration tests

## Changes

- `machine/test/folder-tools-launch.test.js`: added launcher tests for clean bytes, raw and escaped keys, exact reply ids, notifications and requests, work-budget exhaustion, both batch positions, oversized requests and the 8 MiB reply. Each records client stdout, server stdin and stderr.
- `docs/plans/server-tool-keys/reports/T4.md`: this report.

T3 already exercised a result echo and oversized replies through the launcher, but did not check all exact bytes and stderr as required here; the result echo is included above, while the existing oversized reply test is retained. T3 also covers request injection at a client-line boundary. No production files were changed.
