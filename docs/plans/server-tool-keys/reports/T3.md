# T3 — keyed server launcher and relay

## Changes

- `machine/lib/tool-launch.js:28`: validates keyed entry names, refuses debugging or changed/missing keys, reads the selected store fresh and passes values only in the server environment. The original keyless pipe/shutdown path remains in place.
- `machine/lib/server-relay.js:6`: `relay({ child, name, values, kill, stdin, stdout, stderr, observe, exit })` checks bounded stdout lines, redacts stderr, injects replies at client line boundaries, applies backpressure and enforces shutdown deadlines. `observe` is an optional line-buffer-length test observer; `exit` defaults to process exit.
- `machine/test/folder-tools-launch.test.js:631`: fake keyed server and launcher integration cases.
- `machine/test/server-relay.test.js:8`: fake-stream measurements for input queue, output memory, pause deadlines and the line bound. Output memory is measured using `process.memoryUsage().external` and writable length.

The requested end-to-end measurement cases are incomplete: the launcher tests do not instrument these quantities, and the fake-stream checks do not meet the brief’s end-to-end requirement. The stream harness and the launcher tests together cover the size, input backpressure and hard deadline cases. The launcher's end-to-end cases do not themselves inspect the held input size, server stdin queue size, or continuous stdout pause; those measurements are made in the separate stream tests. The post-exit pause test also uses fake streams to establish that the exit precedes the pause interval. Individual mutation checks for every new test were not run.

One earlier launcher gate failed because the keyless spawn spy recorded the cleanup reaper's `stdio` rather than the server spawn. The spy was changed to record array-valued stdio; its focused rerun and the full gate passed. Failure excerpt:

## Choices

- `server-relay.js`: optional `observe` callback exposes held line length to the fake-stream bound test; production uses a no-op.
- `server-relay.test.js`: measured output queue and external memory with fake streams rather than a launcher stats file.
