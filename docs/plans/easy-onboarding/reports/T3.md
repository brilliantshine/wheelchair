# T3 — hub harnesses and onboarding

Implemented hub-wide switches, placement and readiness checks, cached machine harness status, install forwarding, placement-based onboarding, and left-out waiting messages.

Files changed:

- `viewer/app/settings.js`, `providers.js`, `balancer.js`, `usage.js`, `ready.js`: settings, names, placement, machine status and readiness.
- `viewer/app/harnesses.js`, `routes.js`: harness status, onboarding and HTTP routes.
- `viewer/app/wc.js`, `viewer/pages/thread.js`: waiting reason output.
- `viewer/AGENTS.md`: router entry.
- `viewer/test/app-balancer.test.js`, `app-kimi-settings.test.js`, `app-harnesses.test.js`: status fixture updates and coverage.
- `docs/plans/easy-onboarding/reports/T3.md`: this report.
