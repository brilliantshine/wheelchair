# R1-2 — Settings Harnesses fixes

## Changed
- `viewer/pages/settings.js`
  - `orderEditor`: edits now keep switched-off providers at their saved index and fill the other slots with the visible providers in their new order (`any` stays last on Lead order; adds go before `any`). The "then whatever's left" toggle keeps saved order.
  - Machine picker: choosing a machine sets `hz.pending`, repaints at once and shows "Checking <machine>…" with no rows or Install button until that machine's `/harnesses` answer (or error) arrives.
  - Install / Try again use `hz.machine` (the picker's machine), and do nothing while `hz.pending`. `pollInstall` stops itself, before and after each request, if its machine is no longer `hz.machine`.
  - `setHarness`: after a successful switch-off PUT, closes the sign-in card if it was opened from that harness's row.
- `viewer/test/app-harnesses.spec.js`: three new tests (hidden-entry order for Workers try first and Lead order; Install after a picker change with held response; sign-in card closes on switch-off).
