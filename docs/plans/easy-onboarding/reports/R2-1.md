# R2-1 — Add account provider and sign-in card on switch-off

## Changed
- `viewer/pages/settings.js`: new `addProviders()` (the one list of offered providers) used by the Add account button default and the picker; `addForm()` renders nothing when it is empty; `setHarness` resets `adding.provider` to the first offered one (or closes the form if none) after a switch change, and re-renders Accounts; sign-in card now carries `provider`, and `setHarness` closes it when `harness === provider || provider === provider`.
