# T1 report — blocked

Implemented the switch route and background transcript copy, launch preparation, resume commands, readiness handling, hook suppression and renderer prompt response. The full suite failed twice with Windows bridge failures associated with missing `wslpath`; per the task rules, stopped after the second failure. The first run also found an optional-context adapter error, fixed before the second run.

The implementation is incomplete for handoff: the requested exhaustive integration coverage was not finished. In particular, tests still need HTTP-level contract and conflict coverage, actual launch-preparation and environment checks, copy/preparation/respawn failure injection, relaunch exit, and plain-start readiness regression checks. The copy test stubs launch preparation and transcript flushing. Review the implementation before use; passing the focused tests is not proof of the full contract.

- `machine/adapters/claude.js`, `machine/adapters/codex.js`: resume commands and Claude renderer prompt.
- `machine/API.md`: route and event contract.
