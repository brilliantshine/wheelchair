# T1 — Runner cancel handle

- `machine/lib/tool-run.js`: accept an abort signal for keyed and keyless runs, stop only the affected process group, mark keyed streams cut, remove listeners on close, and reject already-aborted runs without spawning.
- `machine/test/folder-tools-run.test.js`: test cancellation and concurrent isolation, and already-aborted signals, for both paths.

The new tests were run against the original runner before implementation, breaking the requested behavior: all four failed. The implementation was then added and the requested validation passed.

## Choices

- `machine/lib/tool-run.js`: Track an abort separately so a child that handles SIGTERM and exits zero still resolves `ok: false`.
- `machine/test/folder-tools-run.test.js`: Exercise both keyed and keyless paths for each requested cancellation scenario.
