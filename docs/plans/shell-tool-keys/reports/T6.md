# T6 report

Changed `machine/test/tool-machine-run.test.js` with isolated refusal, key store, caller PATH and environment, late key, disconnect, stop, discovery race and exit-handler coverage. Changed `machine/test/folder-tools-launch.test.js` to start a worker on a separate linked worktree and check project and shared missing-key wording. No service fix was needed. The stop test calls `abortToolRuns` directly, as permitted by the brief.

Fault checks: the invalid, keyless, missing, ended and ineligible refusal tests each failed after its route status was deliberately changed; the server test failed after changing its server-specific status. The store test failed when the store was replaced by an empty store; PATH failed when discovery received a bad PATH; environment failed when the stored override was replaced; late-key failed with a permanently empty store. Disconnect failed with the close abort removed, stop failed with the abort helper disabled, discovery failed with the aborted check removed, and exit handlers failed with the install call removed. Each service change was restored. The worker worktree test failed when its fixture passed the thread worktree instead of the worker worktree, then was restored; this fault check did not independently break the shared wording. An initial server fault check passed because the server fixture was invalid; removing its key declaration made it reach the server-specific refusal, and the repeated fault check failed as intended. An initial disconnect fault check timed out because the deliberately broken service left a child alive; cleanup was added and the repeated check failed within the deadline.

The initial development run failed once because an empty keys array is invalid rather than keyless; omitting keys fixed the fixture. No service behavior was changed. The linked-worktree test's shared wording has no independent fault injection because `prepareLaunch` is outside the permitted service edit boundary; its assertion is present and passes.

## Choices

- `tool-machine-run.test.js`: used the exposed abort helper for session-stop coverage and a child that is reaped by its parent on SIGTERM to avoid orphan zombie timing.
- `folder-tools-launch.test.js`: used a real linked Git worktree and included a shared tool in the same test.
