# T4 report

- `viewer/app/tool-cli.js`: added machine dispatch for keyed runs, response validation and connection handling.
- `viewer/test/wc-tool.test.js`: added stub machine and fallback coverage.

Both added tests were checked by breaking machine dispatch and watching both fail; the implementation was restored. The first validation failed because the stub allowed connection reuse while shutting down; the stub now explicitly closes that connection.

## Choices

- `tool-cli.js`: treat a recognized unreachable socket error as definitely not run until both socket connection and request finish have occurred; all other transport failures are uncertain.
- `tool-cli.js`: validate all seven documented result fields before printing output.
