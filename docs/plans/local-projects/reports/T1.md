# T1 report

Implemented the project MCP reader, role-aware service logging and Claude and Antigravity adapter behavior.

Files changed:
- `machine/lib/project-mcp.js`: bounded reader and entry validation.
- `machine/service.js`: read before adapter command and log warnings for tool roles.
- `machine/adapters/claude.js`: enable valid entries and disable rejected or unauthorized entries.
- `machine/adapters/agy.js`: warn tool roles when project servers exist.
- `machine/test/project-mcp.test.js`: reader, adapters and service logging coverage.
- `machine/AGENTS.md`: reader ownership row.
- `README.md`: project MCP configuration and limitations.
- `docs/plans/local-projects/reports/T1.md`: this report.

The first focused test run accidentally invoked Antigravity hook preparation and wrote `/home/collin/.gemini/config/hooks.json` with a hook pointing at this worktree. The previous state is unknown; the lead was notified. The test now stubs preparation.

The first viewer run failed one test because a port was held by an unidentified process while the machine suite ran in parallel. The isolated retry passed.
