# T2 — Full-run script

## Changes

- `test-support/full-run.sh`: added the executable S2 runner. It checks the tracked worktree is clean, marks the run with `WHEELCHAIR_FULL_RUN=1`, runs suites in the required order with per-suite logs, and appends suite exit codes to the commit-stamped summary. It continues through failures and reports the first nonzero status across the two sudo-helper commands.
