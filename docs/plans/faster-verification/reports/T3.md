# T3 — Browser workers when alone

- `test-support/browser-workers.js`: selects and carries the count through the environment, tracks full runners by PID, removes stale entries, and unregisters on exit.
- `viewer/playwright.config.js`: uses the decision while preserving both projects and the CLI override.
- `test-support/test/browser-workers.test.js`: tests selection, stale and live entries, own PID, and registration lifecycle in helper-managed temporary directories.

Playwright's `lib/runner/index.js` loads the config in the runner and `ProcessHost.startRunner` forks with `...process.env`; `lib/common/index.js` reloads serialized config in children. The background full run showed exactly one registry entry, confirming children inherited the choice rather than registering.

## Choices

- `test-support/browser-workers.js`: ignore non-PID filenames and propagate unexpected filesystem or process errors; only ESRCH identifies a stale entry.
- Browser validation: repeat the smallest spec to make the configured worker count observable.
