# R1 — verification remediation

## Changes

- `viewer/app/project-lead-actions.js`: extended the refresh machine call to 100000 ms; removed outside thread and peer-log titles from the redaction set; added outside `pr_url`, URL-valued `target_pr`, and `donePr` URLs.
- `viewer/test/helpers/app-machine.js`: added a configurable refresh delay.
- `viewer/test/project-lead.test.js`: added separate regression tests for a six-second refresh, a local question containing an outside title, and all three outside PR URL sources while retaining the local URL. Updated the refresh call assertion for its timeout; changed the cross-thread messages and recent chat assertions to retain title-only mentions while rejecting outside IDs, paths, session names and PR URLs.
- `viewer/app/wc.js`: inspected only; its request has no per-request timeout. The 90-second retry deadline is checked after a request completes, so an individual refresh may wait at least 120 seconds.

Each new regression was run against the original behavior and failed as intended: refresh returned `machine timeout`, question waiting showed `Approval`, and all three outside URLs remained in recent chat. The implementation was then restored and the tests passed.

No screenshots: this change affects hub actions and test fixtures, not a visible screen or mockup.
