# T3 report

- `machine/lib/project-lead.js`: creates a local clone and serializes its refresh with the project repository queue.
- `machine/service.js`: project lead start and prompt, refresh endpoint, agent route and card restrictions, account switch and exclusion from project tools.
- `connectors/codex/machine.js`: forces the project lead sandbox.
- `machine/test/project-lead.test.js`: real Git clone and refresh checks, prompt, sandbox, and agent restrictions.
- `machine/AGENTS.md`: routes the new library.

The thread worktree scan recognizes `wc/` and `wc-` paths only. Archive cleanup selects `created_worktree` sessions; this clone is recorded with that flag false. Verifier cleanup only selects verifier sessions.

The installer fixture failed twice on its check that the live wheelchair directory stays byte-identical. The suite does not identify which live state changed; other sessions and checks were active, so the cause is not established. Per the worker rule I stopped after the second failure. The focused suite does not independently cover every requested case: in particular it does not exercise a second session start, account switch, or an origin/HEAD default different from the local default.
