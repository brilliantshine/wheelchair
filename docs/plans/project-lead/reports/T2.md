## Changes

- `viewer/app/assistant-actions.js`: shared action execution and assistant project-lead exclusion.
- `viewer/app/project-lead-actions.js`: authorization, project scope, filtered reads, card restrictions and refresh.
- `viewer/app/wc.js`: project-lead CLI and read retries.
- `viewer/test/project-lead.test.js`: scoped actions, redaction, start, refresh and CLI tests.
- `viewer/test/assistant.test.js`: assistant project-lead refusal tests.

## Validation

The first expanded project-lead run failed once in the existing concurrent first-send test: the requests arrived in the opposite order. Its retry and subsequent runs passed. The combined picker run preceded the final unsupported-action guard; the targeted project-lead suite passed after that guard. Machine tests and the installer were skipped as directed. No screenshot applies. The requested action tests do not yet cover a second machine with the same project path or a distinct project-lead target, and read retries are exercised for refresh only. The recursive filtering relies on references and peer-log text to identify outside content; unreferenced outside text has not been proven safe. These gaps need follow-up before T2 can be accepted.
