- `runs Codex preflight before a lead start and records its failure as a need`: CLI-selected Codex → set GPT lead order; §5 lead order sentence above; retains failure/card assertions.

- `the Ready check covers the other family and takes Codex login from the preflight`: preflight login → account status login; §1 Ready checks account login status. Other-family and absent-family assertions remain.
- `a lead whose machine refuses the start is recorded as failed, not left starting`: unreachable machine expected failed → waiting; §5 “An account has room when ... logged in on the thread's machine” and “None → wait”. Added a separate reachable machine rejecting POST test preserving the failed-start assertion.
