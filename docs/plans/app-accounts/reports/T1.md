Both runs failed `lifecycle.test.js:420` (the starter retry assertion) and `routes.test.js:170` (inter-400 returns 404); the first run also failed `server.test.js:536` (concurrent write assertion). No viewer files were edited. Coverage is incomplete for explicit default command equivalence, symlink seeding, preflight environment value, and a full Codex turn-end rollout scan. ## Choices

- `machine/lib/statusline.js`: throttle per session using the timestamp file's mtime, and do not send a payload when no rate limits are present.
- `machine/adapters/claude.js`: use `unknown` when a StopFailure payload has neither error field.
