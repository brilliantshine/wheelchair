# T2 report — blocked

Implemented the assigned hub foundation, but the viewer validation gate failed twice, so this task is not complete and should be reviewed before integration.

- `viewer/app/providers.js`: provider registry and CLI mapping.
- `viewer/app/settings.js`: account defaults and normalization, plan weights, balancing settings and GET description.
- `viewer/app/routes.js`: account and balancing writes, usage reads and seen state, and sign-in proxies.
- `viewer/app/usage.js`: queued usage storage, room, forecasts, ranking and cached parallel machine status.
- `viewer/app/ready.js`: account-aware readiness and old-service fallback.
- `viewer/app/chat.js`: CLI parser lookup and unknown-CLI notice.
- `viewer/app/API.md`, `viewer/AGENTS.md`: route and module documentation.
- `viewer/test/app-usage.test.js`: focused checks of settings, forecast, room, rank, Ready, routes and chat.

The viewer suite failed both complete runs: the lifecycle test “a starter that loses the freed port” and the font route test failed in both; the checkout has no `viewer/node_modules/@fontsource` assets. The first run also found a Ready message regression, which was corrected. The second complete run also encountered a port-identification failure. An intervening run ended without a test summary. No further gate iteration was attempted under the two-failure rule.

The lead resolved `within=one`: `usage.json` holds `last_chosen`, and `rank` accepts a trailing last-chosen map or account id. T5 must call the exported `chooseAccount(hub, provider, id)` on each successful pick, including waiting-session promotion; `lastChosen(hub)` reads that map. Missing or ineligible choices fall back to soonest. Some required edge-case tests and sign-in proxy tests remain to be completed, and this implementation needs review against the full contract before use by T5.

## Choices

- `settings.js`: changing a plan without an explicit weight sets the new plan's default weight.
- `routes.js`: empty slug names use `account` and collision suffixes are numeric.
