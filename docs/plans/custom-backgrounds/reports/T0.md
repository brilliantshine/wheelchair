## Decisions

- Expose chosen stateDir in the test-server return context to check isolation and support sequential restart cases explicitly.
- Use command-local init.defaultBranch=main for final Node validation because the existing slug tests assume main; no production code or persistent Git configuration was changed.

## Integrated setup diagnosis

Independent focused backend rerun after partial integration: 2/2 passed (683.55324 ms). Independent focused Chromium run of background-editor.spec.js: 3/3 passed (4.8 s).

Firefox initially hung before its protocol pipe became ready. Direct bounded launch attempts reproduced it independent of feature tests. The sandbox allows writing only the worktree and /tmp. Giving Firefox a temporary writable XDG_CONFIG_HOME resolved startup; HOME and real browser/user state were never changed. Writable XDG cache/runtime directories and GSETTINGS_BACKEND=memory remove incidental desktop cache writes. PLAYWRIGHT_BROWSERS_PATH points explicitly to the existing downloaded binaries because changing XDG_CACHE_HOME changes Playwright's default binary lookup.

