# T7 — focused network and async ownership validation

## Changes

- `viewer/test/background-network.spec.js`: ten real isolated-server cases cover held older HTTP metadata, abort and visible polling, saved-image timeout/retry, native candidate completion ordering, a dropped response after actual commit and conflict recovery, failed replacement fallback and reset/missing metadata, slow replacement editing, same-section rebuild during Save, and a late failed Save after reopening. The image gate holds callbacks only after native load/decode and leaves current choices to use real decoding. Missing metadata is simulated by modifying an actual HTTP response; other failed image loads use browser route aborts.
- `viewer/test/background-editor.spec.js`: replaced the resize shortcut with a same-hash `hashchange`, verified actual editor DOM replacement, draft controls and native preview image identity; retained the ten existing cases.
- No source or router changes; no source gap was found. Full suite remains the sub-lead's responsibility.

The initial timeout test allowed the scheduled refresh to race the transient error; hiding the page while advancing the clock made the timeout observation deterministic. The initial section-exit check read immediately after a hash link click; waiting for restoration fixed the asynchronous navigation assertion. Each failed individual gate passed on its second invocation.

Headless screenshots from the final suite: `/tmp/backgrounds-T5-artifacts/chromium-settings-1280.png`, `/tmp/backgrounds-T5-artifacts/chromium-settings-390.png`, `/tmp/backgrounds-T5-artifacts/firefox-settings-1280.png`, `/tmp/backgrounds-T5-artifacts/firefox-settings-390.png`.
