# T3 backend completion

## Changes

- `viewer/pages/background-format.js`: readable bounded PNG/JPEG/WEBP/GIF walkers; dimension, frame/payload and length checks; GIF empty comments, loop replacement, promotion and preservation.
- `viewer/app/background.js`: readable bounded reader, queue transaction and routing; private directory permission before publishing; no-sniff and sanitized errors; expose the transaction for targeted fault injection.
- `viewer/test/background-completion.test.js` and `viewer/test/fixtures/background/`: API, security, limits, concurrency, persistence, GIF and targeted fault checks. JPEG input is a synthetic structurally valid container, consistent with the deliberate no-decoder contract; WEBP uses a small VP8 image.

## Validation

Each invocation used its own `mktemp -d /tmp/backgrounds-T3-XXXXXX` as TMPDIR, with output redirected to that directory's test.log. The first run failed because the new static GIF test sliced one byte past its frame; the fixture boundary was corrected before the second run. The final run includes the later transaction readability and cleanup-response test changes. Full Node suite was assigned to the sub-lead and was not run.

## Choices

- `viewer/pages/background-format.js`: Require containers to end at their terminal marker rather than accept trailing arbitrary bytes; the brief did not specify trailing-data handling.
- `viewer/app/background.js`: Export `commit` for a narrow in-process filesystem fault test; the brief allowed targeted unit seams but did not prescribe their interface.
- `viewer/test/background-completion.test.js`: Use a synthetic JPEG container to exercise minimum structural validation, since the contract does not require pixel decoding.
