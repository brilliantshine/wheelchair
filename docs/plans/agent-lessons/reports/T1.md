# T1 — agent lessons backend

- `viewer/app/settings.js`: normalize and persist lessons, apply agent changes in the settings queue, render filtered role layers and previews, and exclude lessons from the template size guard.
- `viewer/app/routes.js`: expose lessons and merge Settings edits/removals.
- `viewer/app/card.js`, `viewer/app/cards.js`: validate and accept lesson cards, preserving snapshots and suppressing duplicate notices.
- `machine/service.js`: synchronously relay lessons and refuse when the hub cannot confirm them.
- `viewer/test/app-lessons.test.js`: exercise the backend and machine relay.
