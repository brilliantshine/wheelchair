## Choices
- Removal flow: Remove -> "Really remove" marks the row "will be removed when you save" (struck through, with Undo); nothing is sent until Save (settings.js).
- Thread titles for "saved from" come from `GET /threads?view=list`, fetched when an editor opens (settings.js).
- The group label shows for a role that has lessons but no templates; with neither, no group (settings.js).
- Empty entry shows no Save button, only the note (settings.js).
- Page text for the role heading uses the existing role label ("Checker" for verifier); notice and empty text use "verifiers" as the spec says.
- Client rejects an empty or over-300 edit before sending (settings.js).
- Test lesson ids use the server's `L` + 6 hex format; "Needs you" is checked via `/features` needs and no `.card-needs`, since the nav always has that label (spec).
