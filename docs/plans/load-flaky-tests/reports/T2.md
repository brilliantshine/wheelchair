# T2 — Full-run stop and no re-run

`test-support/full-run.sh`: the browser job leader could exit before its child handled TERM; waiting on leaders was insufficient. TERM and HUP reproduction below shows viewer-node stopped but browser did not. The runner now probes both process groups every 0.1 s, gives them up to 45 s, sends KILL to survivors, and probes for up to 2 s before exiting without a summary.

`test-support/test/full-run.test.js`: the old fixture wrote start before installing its trap, allowing a signal to race readiness. The trap is installed first; the start record includes PID and command. The browser trap waits for viewer-node's stop and another second, and the signal cases check both stop records, absence of summary, and ESRCH for both PIDs. Failure cases check one start per command, including both sudo-helper commands; this verifies the no-re-run rule. No extra tests changed.

The first validation run failed because a no-argument stub recorded a trailing space, so the new command match failed. Parsing now trims that whitespace; the subsequent validation passed.
