# R2 — archived image redraw

## Changes

- `viewer/pages/thread.js`: added `t.archived` to the chat render signature so archive changes redraw chat cards.
- `viewer/test/app-diagrams-uploads.spec.js`: added a no-reload browser regression test. It seeds an image in the uploads directory, confirms the image loaded, archives the open thread, then expects the removal notice and zero image elements.
