# T6 — upload cancellation

## Changes

- `viewer/app/machine-client.js`: identify errors emitted by the machine HTTP request.
- `viewer/app/routes.js`: return 409 for a machine connection failure during upload when possible, destroy a response after headers are sent, and destroy both upload and file responses if the machine response stream errors.
- `viewer/test/helpers/app-machine.js`: add an opt-in mid-body upload reset.
- `viewer/test/app-hub.test.js`: verify that reset returns the specified 409 JSON response.
