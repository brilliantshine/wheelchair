# R3 — duplicate header scan

- `machine/lib/project-mcp.js`: replaced recursive descent and its silent catch with an iterative frame stack; duplicate detection remains per headers object and uses decoded keys.
- `machine/test/project-mcp-reader.test.js`: exercises deep arrays and objects before and after servers and maximum depth within the file limit.

15,000 nested objects cannot fit within the reader's 32 KiB limit: even an empty-key object adds five bytes per level. The object fixtures instead use the maximum depth that fits; the array fixtures include 15,000 levels and the maximum depth that fits.

The first focused run failed two duplicate-marking assertions because a frame reused its path key for its current member key. Separating those keys fixed the failure; the rerun and full suite passed.
