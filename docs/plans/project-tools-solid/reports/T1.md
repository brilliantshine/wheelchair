# T1 report

- `machine/lib/project-mcp.js`: validates SSE and HTTP headers, emits structured lines, and hashes file bytes.
- `machine/adapters/codex.js`: translates supported headers, reports transport and header skips, redacts every override index, and budgets UTF-8 bytes.
- `machine/test/project-mcp-codex.test.js` and `machine/test/project-mcp-reader.test.js`: cover the new contracts.

The machine suite has two expected failures in `machine/test/project-mcp.test.js`: `invalid entries are disabled independently, including when all are invalid` expects a string warning, and `service start logs warnings only for tool roles` expects the old service log text. T4 owns that file and service logging.
