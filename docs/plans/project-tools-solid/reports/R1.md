# R1 — duplicate HTTP headers

- `machine/lib/project-mcp.js`: scan valid JSON for duplicate case-folded header keys and mark validated HTTP/SSE entries with a symbol.
- `machine/adapters/codex.js`, `machine/adapters/agy.js`: honor the marker at the existing duplicate-header check.
- `machine/test/project-mcp-reader.test.js`: cover exact, case, escaped and overwritten header objects, unrelated paths, and serialization.
- `machine/test/project-mcp-codex.test.js`, `machine/test/project-mcp-agy.test.js`: check marked entries are skipped without tool configuration.

## Choices

- `machine/lib/project-mcp.js`: represent array positions with a null path component so array contents cannot masquerade as object-key paths.
- Adapter tests set the shared symbol directly, as permitted by the brief; reader tests separately exercise file parsing.
