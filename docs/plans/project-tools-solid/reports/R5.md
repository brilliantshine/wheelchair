# R5 — Antigravity sweep tmux name spelling

## Changes

- `machine/service.js`: the synchronous Antigravity sweep now treats a decoded name as live when either the machine spelling or its tmux spelling (with `.` and `:` rewritten to `_`) is present. Added the requested comment. The `startingNames` check and the age/removal behavior are unchanged.
- `machine/test/project-tools-service.test.js`: covers keeping an aged `wc-dot.name-worker` directory when tmux lists `wc-dot_name-worker`, and removing an aged `wc-other.name-worker` directory when neither spelling is live.
