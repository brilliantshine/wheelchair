# R7-1

## Changes

- `viewer/app/threads.js`: persist cleared aside turns and pending cancellation IDs before machine calls, retain failures, and continue archiving.
- `viewer/app/asides.js`: retry pending cancels outside the thread lock, serialize sweeps per thread, and remove confirmed IDs under the lock.
- `viewer/app/hub.js`: retry on startup and the aside timer.
- `viewer/pages/aside.js`: refresh the panel when archived changes.
- `viewer/app/API.md`: document pending cancels.
- `viewer/test/app-asides.test.js`: cover partial cancellation and startup retry.
- `viewer/test/app-asides.spec.js`: cover an open panel becoming read-only and wait for the intercepted request before checking it.

The full Node suite failed only the known baseline test “a starter that loses the freed port registers through the new holder.” The first browser run failed because its existing assertion read the intercepted request before Firefox delivered it; the second passed after waiting for the request.
