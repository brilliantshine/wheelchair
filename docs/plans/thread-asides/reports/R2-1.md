# R2-1 report

## Changes

- `viewer/app/asides.js`: split the pump into locked claim and apply phases and unlocked machine calls and acknowledgements; coalesce per-thread pumps and drain newly runnable messages iteratively.
- `viewer/app/hub.js`: mark timer calls so they do not queue a rerun.
- `viewer/app/routes.js`: return aside route responses without waiting for the pump.
- `viewer/test/app-asides.test.js`: await route pumps where needed and cover held GETs, coalescing, close, and archive races.
