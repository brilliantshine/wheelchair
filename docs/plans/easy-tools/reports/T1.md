# T1 report

- `machine/lib/folder-tools.js:1` validates and normalizes descriptions, discovers folders and builds MCP entries.
- `machine/lib/tool-run.js:1` runs scripts, captures output and manages process groups.
- `machine/lib/mcp-stdio.js:1` implements standalone stdio serving and handshake; `machine/lib/tool-bridge.js:1` and `machine/lib/tool-launch.js:1` provide the script bridge and server launcher.
- `machine/test/folder-tools.test.js:1` and `machine/test/folder-tools-run.test.js:1` cover descriptions, discovery, RPC, output, environment and group cleanup.

The description validation test was observed failing when the default timeout was changed from 120 to 121, then the code was restored. The individual remaining test cases were not each mutation-tested.

## Choices

- `tool-run.js`, `tool-launch.js`, `mcp-stdio.js`: a detached reaper delivers SIGKILL after five seconds even if the starter has exited.
- `folder-tools.js`: empty executable names are rejected, and input descriptions must contain non-whitespace text.
