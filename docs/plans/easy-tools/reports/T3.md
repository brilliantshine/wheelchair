# T3 — folder entries in connectors

Claude adds folder entries alongside replacements to its MCP configuration and loaded list (`connectors/claude/machine.js:77`). Codex validates and budgets entries in order, sets the bridge timeout, and warns instead for sandboxed sessions (`connectors/codex/machine.js:165`). Antigravity includes extras in its plugin (`connectors/agy/machine.js:37`); Kimi and Pi warn for server tools (`connectors/kimi/machine.js:311`, `connectors/pi/machine.js:138`). Tests cover these paths (`machine/test/project-mcp.test.js:94`, `machine/test/project-mcp-codex.test.js:145`, `machine/test/project-mcp-agy.test.js:70`).

The test `Claude adds folder entries alone and beside replacements only when tools are enabled` was watched fail after deliberately disabling extras, then the implementation was restored.

## Choices

- Folder entries in `loaded` use `windows: false, wrapped: false`, since their commands invoke the local Node bridge or launcher rather than Windows programs or project wrappers.
