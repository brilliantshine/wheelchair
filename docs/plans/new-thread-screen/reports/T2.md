## Choices
- `viewer/app/threads.js`, `checkProject`: a 404 from the machine on the check (older service) gives `502 "<machine> needs updating"`; any other failure gives `502 "<machine> is not reachable"`. A reply with no `checked.ok` boolean is "needs updating".
- `viewer/app/routes.js`, `POST /settings/saved-dirs`: success status is `201` (the Spec says only "Returns {saved}"); `DELETE` returns `200`. A missing `machine` in the body defaults to `hub`.
- `viewer/app/routes.js`, `POST /settings/saved-dirs`: the duplicate-name `409` is checked before the machine check, and again inside the settings write; the message is "<name> is already saved for <machine>".
- `viewer/app/routes.js`, `GET /new-thread`: unknown machine returns `404 "unknown machine: <name>"`; `previous` is ordered by thread `created_at`, newest first.
- `viewer/app/routes.js`, `PUT /settings/preferences`: a non-string `default_project_folder` is `400`; the response gained `default_project_folder`.
- `viewer/app/threads.js`, refusal message uses the machine's returned `checked.path`, falling back to the submitted path.
- `viewer/test/helpers/app-machine.js`: a failed check for a relative path returns `{ok:false, reason}` without a `path`.
