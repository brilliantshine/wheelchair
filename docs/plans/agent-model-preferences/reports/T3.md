## Choices

- `settings.js` previews: used the Spec's `Provider: model (effort)` format over the mockup's model-only names.

- `settings.js` role disclosures: opening one closes any other, and Escape closes it, so desktop popovers never cover each other.
- `settings.js` saves: tier and order changes show at once and are sent one after another; a refused latest save restores the last accepted value.

- `app-settings-hold.spec.js`: added bottom padding in the test so the page can still scroll now that Balancing is shorter.
