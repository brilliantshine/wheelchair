# R1-1 — Machine install remediation

## Changes

- `machine/lib/harness-install.js`: replaced the synchronous Pi/Kimi adapter lookup with an awaited `run('sh', ['-c', ...])` lookup. Pi uses the resolved command text; Kimi retains its `~/.kimi-code/bin/kimi` fallback and executable check. Spawn errors now resolve with `status: null`, preserving callers' `?? 1` behavior. Removed the now-unused adapters import.
- `machine/test/harness-install.test.js`: added regression tests for a slow Kimi lookup stopped by the install limit and a missing `python3` step program returning exit code 1.
