# T1 report

Implemented the machine side of idle usage polling.

- `machine/service.js`: hub-authorized usage route, account validation, timeout and reading stamping.
- `machine/adapters/claude.js`: isolated Claude probe, usage parser and IANA reset conversion.
- `machine/adapters/codex.js`: rate-limit RPC probe and response parser.
- `machine/lib/usage-probe.js`: asynchronous child runner, timeout and RPC response handling.
- `machine/API.md` and `machine/AGENTS.md`: route contract and helper ownership.
- `machine/test/accounts.test.js` and `machine/test/service.test.js`: parser, shim, authorization and timeout coverage.

Nothing remains undone. The first validation run passed, but the timeout shim also hung status's version and auth checks; I killed those two shim children, corrected the shim, and reran. The final run includes the malformed-body guard added after the second run started.

## Choices

- `machine/lib/usage-probe.js`: use SIGKILL on timeout to ensure the timed-out child exits.
- `machine/service.js`: expose a service constructor timeout option for fast timeout tests; production defaults to 30 seconds.
