# R3 — spot draft clears on acceptance

## Changes

- `viewer/pages/thread.js`: after the hub accepts the spot comment, render the pending bubble and return from `send`; start `poll()` without awaiting it.
- `viewer/test/app-spot-comment.spec.js`: add a regression test that holds the chat GET after accepting the messages POST and checks the pin and box disappear while the pending bubble is visible.
