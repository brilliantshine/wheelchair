# T3 report: comment on a spot in a mockup (S2)

## What changed
- `viewer/pages/diagram.js`: new `spotText()` and `spot(host, after, spec, opts)` (exported as `WCDiagram.spot`). Builds the "Comment on a spot" button, the transparent layer (iframe untouched, still `sandbox=""`), the pin and the box (hint, textarea, Send, Cancel, error). Drafts live in a module `Map` keyed card id + `|` + graph; a redrawn node rebinds to the same draft. Tap -> pixels: divide by `min(1, layerWidth / width)`, round, clamp to 0..size-1. ## Choices
- Message `<title>` is the card's own title (image cards: without the "Mockup: " prefix). diagram.js / thread.js `spotButton`.
- The spot UI lives in `diagram.js` (`WCDiagram.spot`), shared by both pages, not a new file.
- Before the first tap the box shows "Tap the spot on the mockup." and Cancel only; Send and the textarea appear with the pin.

- Picture bar made `flex-wrap: wrap` (picture.css) so the added button doesn't push Download off a phone screen.
- Edited `app-threads.spec.js:858` (see above) although it is S1's assertion, since it is in the validation list.
