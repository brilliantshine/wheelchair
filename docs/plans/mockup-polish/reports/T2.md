# T2 report — mockup PNG download (S3) and screenshot view (S4)

## Changed
- `viewer/pages/picture-export.js`: new `mockupCanvas(src, w, h)` (exported) beside `graphCanvas`/`formCanvas`. Fetches the mockup HTML, parses it, strips scripts and `on*` attributes, rewrites `:root` to `html` in `<style>` text, reads the canvas background (html's, else body's) from computed style in a hidden script-free `sandbox="allow-same-origin"` srcdoc iframe, moves it to a w x h root box (the source element's own background is set to none), serializes as XHTML in a `foreignObject` of exactly w x h, loads it from a `data:image/svg+xml` URL, draws on a canvas sized by `scaleFor`, white first; a tainted canvas throws.
- `viewer/pages/picture.js`: mockup branch now offers PNG through `offerPng` (new optional failure text: "This browser could not make a PNG of this mockup. Download HTML instead.") plus `#download-html` link; new `showImage` for `view=image` (natural size, Download link to the file, removal text when archived and not kept).
- `viewer/pages/picture.html`: `#download-html` link. `viewer/pages/picture.css`: its placement and `img.picture-shot` with no max-width.
- New `viewer/test/app-mockup-png.spec.js` (6 tests) and `viewer/test/app-screenshot-view.spec.js` (2 tests).

## Choices
- Background read via a hidden sandboxed srcdoc iframe's computed style (not CSS parsing); copies colour, image, repeat, position, size. (picture-export.js)
- Download HTML link id `#download-html`, shown left of Download. (picture.html/css)
- Screenshot view finds any non-retracted image card with a file, mockup or not; Download link carries `download` = card name. (picture.js)
- Inline `on*` attributes are stripped as well as scripts. (picture-export.js)
