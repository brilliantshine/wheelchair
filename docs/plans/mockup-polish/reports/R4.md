# R4 — rem sizes in the mockup PNG

## Changes

- `viewer/pages/picture-export.js`: renamed the page probe to `readMockupPage`, read computed root font size with the existing canvas background, and apply a validated pixel font size to the outer SVG.
- `viewer/test/app-mockup-png.spec.js`: added a `62.5%` root-size mockup fixture and checks the green and white pixels at export scale 2.
