# R1 — mockup-polish remediation 1

## Changes
- `viewer/pages/thread.js` `chatPlace()` (~135): records only entries whose bottom is below the lowest bottom edge of the visible `#head`, `#dead` and `#pinned` bars (`covered`).
- `viewer/pages/thread.js` `cardSig()` (~670): `frozen()` is null for `diagram` and `image` cards. Their drawing never reads it (`off` is not used in those cases); the spot button follows `canSendNow()` in place. Also the final `if (frozen()) ... disabled` loop in `renderCard` skips those two kinds so the drawing and signature agree.
- `viewer/pages/picture-export.js` `canvasBackground(html, w, h)`: the helper iframe is w x h (800x600 fallback); `mockupCanvas` passes its w, h.
- Tests: `app-chat-stability.spec.js` (hidden-under-header anchor), `app-spot-comment.spec.js` (hand-off: same iframe, 0 loads, button hidden), `app-mockup-png.spec.js` (390x300 narrow media query exports green).

## Choices
- Covered area is the max bottom of `#head`, `#dead`, `#pinned` when visible (not the nav, which is above and never overlapped by chat rows reaching only to y>0 meaningfully; head sticks below it so head's bottom already exceeds it).
- Diagram/image cards also skip the frozen disabling loop, so an open draft's buttons stay as they were; Send is still refused by `cantSendWhy()`.
