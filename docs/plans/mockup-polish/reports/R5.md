# R5 — mockup root font size applied twice

## Changes

- `viewer/pages/picture-export.js`: resolve the validated pixel root size once; apply it with `!important` to the wrapped `html` style and reuse it on the SVG root.
- `viewer/test/app-mockup-png.spec.js`: add the `em` fixture and pixel test for rem and em dimensions at the expected root size.
