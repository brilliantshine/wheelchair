# R3 — auto-focus bound and probe failures

## Changes

- `machine/lib/screen-input.js`: Bound the baseline scan by the shared phase deadline, accepted the phase start time, and restricted strict child-probe skips to vanished-window errors while retaining stderr.
- `machine/lib/screen.js`: Start the phase before the baseline and pass its deadline and start time to the input helpers.
- `machine/test/screen-input.test.js`: Cover vanished-window variants, unexpected errors, and baseline and autofocus deadlines.
