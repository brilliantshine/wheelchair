## Choices

- `viewer/test/wc-screen.test.js`: kept the helper name and signature `runWithServer(args, response = default 200 response)` from Attempt 1.
- `viewer/test/wc-screen.test.js`: used `status` for the 422 response case.
- `viewer/test/wc-screen.test.js`: identified matching requests by POST, URL ending in `/screen`, the test token, and a JSON-parsable body.
- `viewer/test/wc-screen.test.js`: returned 404 and ignored malformed JSON or nonmatching requests; valid matches are collected in `received` and each CLI test asserts exactly one.
- `viewer/test/wc-screen.test.js`: the unknown-op test uses a counter incremented only for parsed matching requests and asserts it stays zero.
- `viewer/test/wc-screen.test.js`: closed the server with `finally` in both the shared helper and unknown-op test.
- `viewer/test/wc-screen.test.js`: named the additional unit test `screenRequest rejects unknown and missing operations`.
