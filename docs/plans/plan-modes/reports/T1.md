# T1 report

## Changes

- `viewer/app/card.js`: validate and expose deferred cards; allow their retraction.
- `viewer/app/cards.js`: pin deferred as a singleton.
- `viewer/app/threads.js`: validate pull-back presses, keep deferred unanswered, and include card kinds and stub summary in restart context.
- `viewer/pages/thread.js`: reuse idea rendering for deferred, with mode text, pull-back controls and lock handling.
- `viewer/test/app-hub.test.js`, `viewer/test/app-threads.spec.js`, `viewer/test/protocol-rules.test.js`: add app and browser coverage and update kind/refusal lists.
- `protocol/app/cards.md`, `protocol/app/cards-lead.md`: document deferred and pull-back refusals.

## Validation

The Node gate failed twice in the new test. First it expected HTTP 200 rather than the actual 202; after correcting that, it expected `answered` to be undefined although cards initialize it to false. The second assertion is at `viewer/test/app-hub.test.js:2130`. The remaining assertions in that test have not run. Worker rules require stopping after the same gate fails twice.
