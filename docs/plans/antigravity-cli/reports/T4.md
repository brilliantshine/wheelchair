# T4: Antigravity machine sessions

- `machine/adapters/agy.js`: added commands, trust settings, atomic global hook merge, screen parsing, Stop translation and conversation binding, and login support.
- `machine/adapters/index.js`: registered the adapter. `hook-post.js` already dispatches by adapter and needed no change.
- `machine/hook.sh`: accepts Antigravity hooks with the session name from the environment.
- `machine/service.js`: prepares adapters, supplies the session environment, polls permission prompts, detects completed logins, reports status, and recovers Antigravity sessions.
- `machine/test/accounts.test.js`, `machine/test/service.test.js`: added fixture and isolated service coverage; fake binaries include agy.
