# T0: live agy 1.5.9 check

## Findings affecting the Spec

- `--settings` rejects a `hooks` key with `Error: --settings: unknown setting "hooks"`. The global hooks fallback works, but a successful Stop's `terminationReason` was `NO_TOOL_CALL`, not `model_stop`.
- The live `--conversation` call returned the **same** ID as the interactive conversation; the pane did not show the injected turn. It is not evidence of a fork.
- Neither named isolation candidate nor either other tested variable satisfied the isolation test. All four saw the default signed-in models and changed files under `~/.gemini`.
- The available model IDs are in `models-signed-in.txt`; pin selection remains a lead decision. The permission-prompt screen and plan-mode enforcement remain unproven.

## 1. Login screens

Login succeeded with Google OAuth. `login-menu.txt`, `login-link-joined.txt`, `login-link-wrapped.txt`, and `login-success.txt` capture the sequence; the URL is removed to protect OAuth values. A separate scratch HOME and deliberately invalid code produced `login-bad.txt`: `token exchange failed: oauth2: "invalid_grant" "Malformed auth code."` The success screen first asks for a color scheme, followed by data-use choices and workspace trust.

## 2. Credential location and bus

A newly updated `/home/collin/.gemini/antigravity-cli/antigravity-oauth-token` is mode 600. After login both `env -u DBUS_SESSION_BUS_ADDRESS agy models` and `DBUS_SESSION_BUS_ADDRESS=unix:path=/run/user/1000/bus agy models` returned the signed-in list and exit 0. This shows both environments can read the account, not an actual subsequent service-launched session; the login itself inherited the session bus environment. No token contents were inspected.

## 3. Isolation

Each command `env VARIABLE=/tmp/t0-agy-check/VARIABLE agy models` returned exit 0 and the signed-in list for `ANTIGRAVITY_CONFIG_REL_DIR`, `ANTIGRAVITY_EXECUTABLE_DATA_DIR`, `ANTIGRAVITY_APP_DATA_DIR`, and `ANTIGRAVITY_GEMINI_DIR`. Comparing file paths, sizes and mtimes before and after showed changes under the default `~/.gemini` (including log and onboarding files); default `agy models` continued to return exit 0 after each. These absolute-directory trials do not rule out other values, combinations or variables. The live interactive session could also write concurrently, but signed-in output itself fails the required isolation test.

## 4. Models and help

Signed-out output and exit 1: `models-signed-out.txt`; signed-in output: `models-signed-in.txt`, exit 0. The available Gemini choices were `gemini-3.8-flash-high`, `gemini-3.8-flash-medium`, and `gemini-3.8-flash-low`; the list also offers Claude and GPT-OSS models. `help.txt` and `models-help.txt` capture both help commands.

## 5. Hook and transcript

`agy --settings /tmp/t0-agy-check/settings.json -p 'reply with the word ok' --output-format json` returned exit 1 and `Error: --settings: unknown setting "hooks"`, with `{"hooks":{"Stop":[{"hooks":[{"type":"command","command":"cat >> /tmp/t0-agy-check/settings-hook.jsonl"}]}]}}` as the settings file. The global file then fired with this exact shape:

```json
{"wheelchair":{"Stop":[{"type":"command","command":"cat >> /tmp/t0-agy-check/global-hook.jsonl"}]}}
```

`stop.json` records its stdin; it contains `lastUserInput` but no last assistant message, and reports `terminationReason: NO_TOOL_CALL`, `fullyIdle: true`. `transcript.jsonl` is the file at its `transcriptPath`, containing `USER_INPUT` and `PLANNER_RESPONSE` records; `idle.txt` shows the ready text. The temporary global hooks file was moved to `/tmp/t0-agy-check/global-hooks-used.json`. Instruction-file discovery was not tested.

## 6. Permission modes

In a scratch git repository, auto mode ran `curl https://example.com` and `chmod 777 /tmp/t0-agy-check/repo/x.txt` without showing a permission prompt (`auto-commands.txt`); two attempts did not produce the requested screen, so no further attempt was made. A separate headless `agy --mode plan -p 'create a file x.txt containing hi' --output-format json --print-timeout 90s` left the file absent, but `plan-output.json.txt` reports a headless command permission denial. This does not independently prove plan mode forbids edits.

## 7. Live conversation aside

While the interactive conversation was running, `agy -p 'reply with the word aside' --conversation <interactive-id> --output-format json` returned exit 0, `status: SUCCESS`, response `aside`, and the same `conversation_id` as `stop.json` (`aside.json`). `after-aside.txt` shows the original turn and idle prompt, with no injected turn visible. The ID is reused; whether the persisted transcript was appended was not separately examined.

## 8. Quota

No quota or rate limit was deliberately provoked. `~/.gemini/antigravity-cli/cli.log` contained Go-style severity/timestamp/file prefixes, authentication errors and quota refresh messages, but no observed quota-exhaustion error; e.g. `I1116 14:05:25.972625 249 quota_manager.go:36] doRefreshQuota: skipped (not logged in)`.
