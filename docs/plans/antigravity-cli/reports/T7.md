# T7 — Graph-arrow browser test skips `form` pictures

## Change

- `viewer/test/browser.spec.js`: the committed graph filter now parses each JSON file once and skips files with either `run` or `form`. The comment explains that timeline, before-after, layers and side-by-side form pictures have no boxes or arrows and are drawn by the app's picture page.
