# T2 — Gemini hub provider

## Changes

- `viewer/app/providers.js`: registered Antigravity and provider capability flags.
- `viewer/app/settings.js`: added Gemini plans, defaults, worker order migration, and review family normalization; saved lead order stays intact.
- `viewer/app/routes.js`: validates Gemini model effort and review family and refuses extra Antigravity accounts.
- `viewer/app/sessions.js`: propagates the Antigravity conversation ID. Existing effort validation permits max for agy and caps only codex at xhigh.
- `viewer/app/asides.js`: refuses Antigravity asides before the parent readiness check and maps provider IDs.
- `viewer/app/balancer.js`: reviewed choose; three-family tests pass without a logic change. `viewer/app/ready.js`: reviewed generic CLI checks; agy gets its installation and Antigravity sign-in checks without a change.
- `viewer/test/app-settings.test.js`, `app-balancer.test.js`, `app-asides.test.js`: added requested coverage. `viewer/test/app-usage.test.js`: updated the existing two-provider review-family error assertion.
