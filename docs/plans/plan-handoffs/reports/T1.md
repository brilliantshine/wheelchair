# T1 — machine handoffs

## Built

All eight ordered milestones were implemented and committed individually after a green machine gate. The follow-up hardening commits are d362051 and 2c573c8.

- `machine/service.js:43` normalizes supported GitHub origin forms. `machine/service.js:1211` fetches exact remote refs with an explicit tracking refspec; `machine/service.js:1223` validates and locks requests before entering the repository queue, and `machine/service.js:1496` exposes the hub-only route.
- `machine/service.js:1264` implements status, push, inspect, claims and revoke, fast-forward, set-branch, known, running, kill and reopen. Status and inspect read committed plan documents; claim pushes and revocations use exact leases; local updates reject divergence.
- `machine/service.js:217`, `machine/service.js:252`, `machine/service.js:342`, `machine/service.js:561` and `machine/service.js:778` implement cancelled starts and durable archiving/archived markers, including reopening and kept-open behavior.
- `machine/service.js:442` adds the ordered remote-branch worktree paths, tracking configuration and archive ownership.
- `machine/test/service.test.js:1394` adds normalization, validation and archive-lock, fetch, status/push/inspect, claim, local branch, session, marker and imported-worktree coverage using bare local remotes and fakes. The service test setup also restores its environment if listen fails (`machine/test/service.test.js:66`).

## Unfinished

No machine-side Spec item is knowingly left unimplemented. The required final viewer validation remains blocked by the two fixture failures above and needs a clean rerun by the lead or verifier.

## Choices

- `machine/service.js`: Store ownership in `archive-markers.json` and serialize marker writes to avoid lost cross-thread updates.
- `machine/service.js`: Return a null current branch for detached HEAD in status, allowing the caller to reject it.
- `machine/service.js`: Identify orphaned checkout ownership by the machine's thread-branch or session-name directory conventions.
- `machine/test/service.test.js`: Restore the fake-command environment after a failed listener setup so a port collision cannot contaminate subsequent tests.
