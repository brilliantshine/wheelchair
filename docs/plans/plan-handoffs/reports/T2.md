# T2 — handoff hub work

Milestones 1–6 are committed. The handoff file, export eligibility and transaction, frozen-thread guards, handed-off banner data, download recovery and startup sweep are available for the downstream hub tasks.

## Changes

- `viewer/app/handoff.js:12` validates the file and `:34` renders plain-text card history. `:50` names downloads, `:55` builds and trims history, `:85` implements the frozen and quiet checks, `:105` selects the committed stage, `:115` orders reasons, `:128` exports, `:196` selects the matching saved file, `:217` sweeps at startup, and `:233` computes banner state.
- `viewer/app/hub.js:38` holds operation, upload and status state; `:56` starts file recovery, `:166` exposes handoff operations, and `:172` caches the page status read for 60 seconds without a PR URL. A failed refresh retains the prior status.
- `viewer/app/routes.js:69` counts uploads under the thread lock; `:429` exposes banner, repeat-download and export routes; `:444`, `:491` and `:554` guard asides, messages and terminal input. The list response marks handed-off threads.
- `viewer/app/sessions.js:213`, `:409` and `:430` guard session starts, enqueue and delivery; `viewer/app/cards.js:53` guards card posts; `viewer/app/threads.js:109`, `:125`, `:165`, `:277` and `:347` guard thread operations. Archive remains available for handed-off threads but refuses unfinished operations.
- `viewer/app/machine-client.js:99` calls the machine handoff endpoint with a two-minute deadline. `viewer/test/helpers/app-machine.js:35` scripts action replies and records requests. No existing hub doubles were changed.
- `viewer/app/API.md:25` documents the new routes and `:59` the payload fields. `viewer/test/app-handoff.test.js:9` covers validation and history, `:66` eligibility, `:94` frozen entry points, `:144` export, `:191` recovery and banner state, and `:221` upload, caching and route cases.

No Spec item in T2's ownership boundary was intentionally left unfinished. Undo itself, the operations engine, import, pages, protocol and machine service belong to the other tasks.

## Choices

- `viewer/app/handoff.js`: filenames strip a trailing separator after the 60-character cut.
- `viewer/app/handoff.js`: history uses newline-separated plain text; a question without an answer is rendered as withdrawn.
- `viewer/app/hub.js`: cache the time of the last page-status attempt as well as the last successful value, so a failure retains the value and does not trigger repeated calls within 60 seconds.

The revoke-list format is the sub-lead's settled JSON array of entries, with a missing or malformed list treated as empty.
