## Remaining

The restart currently treats a recorded worktree path as present; it does not independently check whether that path still exists on the remote machine. The operation engine is expected to clear a missing checkout, but a recorded path that disappears later is not handled. Focused tests do not yet explicitly exercise the second restart marker, transcript replacement, merge watcher, or a partial-start recovery followed by restart. The dead-lead panel must allow an imported thread with no live lead even if no lead was ever started; the page task owns that change.

## Choices

- `hub.js`: Recognise an unsaved start result by `status: starting` and absence of `first_message`; this field is added only after the machine start returns.
- `threads.js`: Preserve all queued messages including prior context when transferring imported lead queues, ahead of which the new context is inserted.
- `handoff.js`: Use `created_at`, falling back to `at`, as the done card creation timestamp.
