# V1 — Kimi launch version recheck

- `machine/service.js:1297` accepts an explicit executable for the cached version check; `machine/service.js:1313` resolves and checks the launch path and mtime, sharing the floor comparison with status at `machine/service.js:1324`.
- `machine/service.js:592` retains the early check; `machine/service.js:622` rechecks after worktree creation and passes the checked path through `machine/service.js:570`.
- `machine/adapters/kimi.js:112` uses the supplied path for launch, falling back to resolution for other callers.
- `machine/test/kimi.test.js:155` swaps the fake binary during worktree creation, checks refusal before tmux, and checks the unchanged binary's launch path.
