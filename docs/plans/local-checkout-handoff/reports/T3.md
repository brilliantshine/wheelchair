- `viewer/pages/thread.js`: the panel (built in JS and inserted after `#head-files`, so `thread.html` is untouched). Status sentences, files with "and N more", earlier branch, index.lock line, `last` with `appeared`, buttons by state, in-page confirmations, kept list with Delete, "Switching…", 3-second re-read while busy, error line, re-read after write errors.
