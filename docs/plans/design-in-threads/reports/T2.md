## Choices
- Thread chat cards are only ~535px wide at a 1280px window, so image halves stack there; the "wide" test uses an 1800px viewport (`app-mockups.spec.js`).
- Mockup box border is 1px on a content-box outer box, so its height is `height × scale` + 2px of border (`thread.css`).
- Built-half "Open full size" link only shown when the image file is still available (`thread.js`).
- Mockup iframe uses `scrolling="no"` and an opaque white background (`diagram.js`, `thread.css`).
- Picture page for an image card without a thread slug says "Mockup not found." (`picture.js`).
