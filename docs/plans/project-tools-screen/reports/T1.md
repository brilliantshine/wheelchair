The first targeted launch test failed because the fake tmux script selected the wrong positional argument; the fixture was corrected and subsequent runs passed.

## Choices

- `project-mcp.js`: retain raw parsed server entries alongside validated entries so malformed entries can still hold back references at launch.
- `project-keys.js`: `projectIdentity` accepts an optional command runner and otherwise uses `execFile`, so the shared function is usable by the later routes as well as launch.
- `service.js`: skip identity and store reads when no eligible references exist; held-back launch names are reported when a stored eligible key would otherwise be injected.
