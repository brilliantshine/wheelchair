# T3 report

- `viewer/app/machine-client.js`: added authenticated strict-JSON pass-through, preserving status and body and detecting dropped responses.
- `viewer/app/routes.js`: added the three browser routes, validation, 120-second forwarding, and transport error handling.
- `viewer/test/helpers/app-machine.js`: added configurable project-tools replies, including delays and raw bodies; requests use the existing call recording.
- `viewer/test/app-project-tools.test.js`: covered forwarding, secrets in hub state, response statuses, failures, timeout, and browser authorization.
- `viewer/AGENTS.md`: documented the client and routes and added the page row.

The existing browser authorization covers the routes; no server change was needed. No Spec/API disagreement found. The first focused run failed because its synthetic request supplied a string rather than a buffer; fixed in the test. The first full run had a port collision in an unrelated server-start test; the retry passed.
