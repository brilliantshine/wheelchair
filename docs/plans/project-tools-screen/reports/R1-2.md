# R1-2 — temporary worktree cleanup

## Changes

- `machine/lib/project-tools.js`: removed the `added` flag. The `finally` block now attempts forced worktree removal whenever a temporary path was chosen, then prunes registered worktrees; both commands use the existing 60-second `git(...)` helper and their result statuses are ignored.
