# R7-2: read-only strings with control characters show visibly

## What changed

- `viewer/pages/project-tools.js`
  - Added `showText(s)` beside `unshowable`: returns the string as is when it has no control character, otherwise its `JSON.stringify` form. Display only.
  - `rowLine`: a read-only row's name and value go through `showText`. The `JSON.stringify` for non-string values is replaced by the same function.
  - `rowEditor`, read-only branch: name and value go through `showText`.
  - `toolCard`: the tool name in the card's `h3` goes through `showText`.
  - `toolCard`, run line: the command pieces, arguments and URL go through `showText`.
  - `openForm`: the read-only command and URL text go through `showText`.
  - Nothing that is saved changed; the save path is untouched.
- `viewer/test/app-project-tools.spec.js`: appended one test, `R7-2: a read-only value with a newline shows in its JSON form, not collapsed`. A tool with env `{ NOTE: "first\nsecond" }` must show `"first\nsecond"` (with a visible `\n`) on its card.

## Choices

- `viewer/pages/project-tools.js` `openForm` (the Arguments read-only line, ~line 524): left as `JSON.stringify(f.p.args)`. It is not on the brief's list, and its output is the same as `showText` for an array.
