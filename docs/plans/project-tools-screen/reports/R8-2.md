# R8-2: read-only cards show every raw field; read-only rows show key status

## Changed
- `viewer/pages/project-tools.js`: deleted `viewEntry`. Editable cards render from `parseEntry` (`p.kind`, `p.command`/`p.args`/`p.url`, `p.extras`, `p.envRows`/`p.hdrRows`). Cards the form can't edit show a chip from `type` only (http = web address, absent/stdio = command, other = as written via `showText`/`JSON.stringify`, non-object = "edit in the file"), every raw field in file order as `name: value` text lines (or one `JSON.stringify(raw)` line for a non-object), a `‹key NAME›` + set/not set chip per name in `checks.keys`, then the unchanged hint, checks lines and Remove. `rowLine(row, kind, toolKeys)`: `ro` rows append `‹key NAME›` chips for `${NAME` matches in a string `row.raw` that are in the tool's `checks.keys`. New shared `keyChip` helper.
- `viewer/test/app-project-tools.spec.js`: five new `R8-2` tests (http+command field order and no Edit button; custom type; editable header key chip set / not set; non-editable key line; HTML as text). Changed existing assertions: `R7-1: a read-only web tool card...` (renamed; now expects `headers: {"A":"plain","B":"Bearer ${TOK}"}` instead of `A = plain`, and its double now supplies `checks.w.keys = ['TOK']` so the not-set chip still appears).
