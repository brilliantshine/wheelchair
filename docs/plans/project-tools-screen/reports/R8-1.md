# R8-1 report

Changed `machine/lib/env-launch.js` to read and remove the JSON environment file and launch the agent; `machine/service.js` writes the file and invokes the launcher. Extended the reserved names in `machine/lib/project-keys.js`, documented the launcher in `machine/AGENTS.md`, and added coverage in `machine/test/project-keys.test.js`.

Node's `process.execve` aborts with a native stack trace on some execution failures rather than throwing. The preflight catches missing and non-executable files, but cannot catch every error, such as an invalid executable format or a race after checking; the lead accepted this limitation to retain execve's process and signal behavior. A hostile-value test exercises an invalid executable and confirms that its output contains no value. No Spec/API disagreement found.
