## Choices
- `app-agents-decks.spec.js`: on desktop, children lay out side by side, so 12 live workers do not make the page scroll. Desktop uses a spacer div (1000px, then 3000px in scenario 3, with `overflow-anchor: none`) prepended to the body instead; phone uses the real 12 + 12 workers.
- Scenario 3 checks the deck is off screen with `expect.poll` after the refresh (not before), since the deck element is briefly absent during a re-render.
- Scenario 3's extra workers and spacer growth are applied before waiting for the refresh, as the data change.
