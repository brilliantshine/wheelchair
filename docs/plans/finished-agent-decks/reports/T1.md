# T1 — round numbers and Agents API data

## Changes

- `viewer/app/wc.js`: rejects a bare `--round`, forwards its value, and includes the stored round in compact session output.
- `viewer/app/sessions.js`: validates the round before deduplication and persists it for queued and immediately started reviewer sessions.
- `viewer/app/agents.js`: derives review rounds from progress cards, parses reviewer reports, and supplies finished-node timestamps.
- `viewer/app/API.md`: documents the additions and retry behavior.
- `protocol/app/lead.md`: instructs leads to supply the review pass to reviewer starts and not to verifier starts.
- `viewer/test/app-agents.test.js` and `viewer/test/app-session-meta.test.js`: cover rounds, report parsing, timestamp fallbacks, validation, and retries.
