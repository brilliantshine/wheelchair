# R2 report — deck title, outlines, popover placement (G3, G4, G5)

## What changed
- `viewer/pages/agents.js`: `deckCard` builds the title once, sets its `title` tooltip to the full text, and sets the deck button's `aria-label` to `<role> ×N: <full title>`. `placePop` now measures the popover, keeps it below the deck if it fits (8px margin, 6px gap), else above if it fits, else on the side with more room with `max-height` set to that room (the popover already scrolls). Top is clamped so the box stays inside the viewport.
- `viewer/pages/views.css`: `.agents-deck .agents-box-title` is one line (`nowrap`, ellipsis, clamp off); the ordinary box title is untouched. Removed `isolation: isolate` from `.agents-deck`, which was why the negative-z outlines painted over the card face (an isolated element's own background paints below its negative-z children). Without it they paint behind the deck's opaque background. Deck gets explicit opaque `background-color` (`--panel`, `--accent-soft` when selected).
- `viewer/test/app-agents-decks.spec.js`: phone viewport is now 390x844 (was 360). Three new cases (Chromium and Firefox, phone and desktop): one-line title with tooltip and accessible name; opaque deck background and positive x/y translate on `::before`/`::after` with negative z-index; popover bounding box inside the viewport (8px) for a deck scrolled to the bottom, before and after opening a round.

## How I confirmed the outlines
Screenshot of the desktop page (scratch, not committed) with a deck at the bottom and its popover open: the popover sits above the deck, and the deck face shows only its own text with the dashed outlines visible only down/right of it. A clipped screenshot of the deck face alone showed no outline lines over the face.

## Choices
- views.css: removed `isolation: isolate` instead of re-layering, since that is the cause of G4 and keeps it CSS only.
- agents.js: popover `aria-label`/min room of 40px floor in `placePop` when neither side has room; chosen so the box never collapses.
- spec: phone viewport changed 360 -> 390 to match the brief's 390x844.
- spec: bottom-of-viewport case forces the deck down with a injected style adding tall margin under `.agents-count`.
