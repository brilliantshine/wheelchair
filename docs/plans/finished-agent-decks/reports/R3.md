# R3 report

## Changes
- `viewer/pages/agents.js`
  - A: scroll listener ignores events from inside `.deck-pop`. `placePop` no longer writes `maxHeight = 'none'`; it measures `scrollHeight + (offsetHeight - clientHeight)` and saves/restores `scrollTop`. `redrawPop` carries `scrollTop` over for the same deck (`data-member` on the box). `render()` (which the 5 s poll runs, and which removed the popover before `redrawPop` saw it) now stashes member and scrollTop in `popKeep` first, so the scroll survives the poll.
  - B: a deck's branch wrapper gets class `agents-deck-branch`.
- `viewer/pages/views.css`
  - B: `.agents-deck-branch { isolation: isolate; }`.
  - C: in the `min-width: 900px` block, `.agents-box.agents-deck { width: max-content; min-width: 190px; max-width: 290px; }`. Phone is unchanged (full width).
- `viewer/test/app-agents-decks.spec.js`: three new cases (popover scroll/poll/click, outline pixel check, untruncated desktop title). Existing cases kept.

## Choices
- Title width: 280px was not enough (needs 259px of text in a 250px content box, so about 289px). Chose `max-width: 290px`, within the 300 cap.
- Outline test: on phone the deck is full width, so the "empty" reference square is 8px above the deck's top edge, at the same x as the outline square (not to its right).
- `render()` stashes popover scroll in `popKeep` (agents.js), beyond the brief's three parts, because the poll's full re-render removes the popover before `redrawPop` runs.
- Title test uses 20 rounds with 20 reviewers (one per round), since the title counts distinct rounds.
