# T2 report — decks, round squares, popover and "?" popout

## Changed
- `viewer/pages/agents.js`: with Hide finished OFF, `arrange()` groups 2+ finished same-role siblings (not asides) into a deck at the newest member's place; the deck's children are its members' merged children (sorted by creation), grouped again. `deckCard()` shows role, `×N`, title (`deckTitle`), round squares (reviewer decks with rounds only), and "Finished HH:MM" via `clock()` on the latest `finished_at` (falls back to `ended_at`). Squares are coloured and labelled per §4. The popover (`redrawPop`) is a fixed-position dialog kept in module state (`pop` = member name, round, all) and rebuilt after every render, so it survives polls and reopens on whichever deck holds the remembered member; it closes if none does. Rounds list newest first with 5-row cutoff, "Show all", an "Other" group, and agent rows that call `go()`. Escape, outside click and a second deck click close it. The `?` button and "How to read this tree" popout sit in a new `.agents-finished-bar` next to the toggle. Question paths and the phone highlight map member names to the deck element (`data-members`); hops inside one deck are skipped.
- `viewer/pages/views.css`: bar, `?` popout, squares, deck outlines (CSS-only `::before/::after`), popover styles.
- `viewer/test/app-agents-decks.spec.js` (new): desktop and phone cases for every item the brief listed.
- `viewer/test/app-views.spec.js`: the existing "finished agents start folded out" case expected 13 boxes after "Show finished"; the 10 finished workers now stack into one deck, so it expects 4 (comment added).
