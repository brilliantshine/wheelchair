# R1-1 — permit relay test

## Changes

- `machine/test/service.test.js`: allowed `permit` for the lead in the fake hub and added the synchronous success/refusal test. The success case checks the hub answer, one `/cards` call with a permit body, and no spool file both while the delayed hub response is pending and after it returns. The 422 case checks the hub error and no spool file.
- `docs/plans/fix-others-prs/reports/R1-1.md`: this report.
