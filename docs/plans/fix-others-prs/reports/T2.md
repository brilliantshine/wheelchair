# T2 — machine relays permit cards synchronously

## Changes

- `machine/service.js`: included `permit` in the synchronous card relay and gave `done`, `lesson`, and `permit` distinct unavailable messages.
- `machine/test/service.test.js`: added coverage for a 503 hub, a hub with a queued card, and no configured hub. The test was first run against the old behavior and failed because permit returned 202 instead of 503; after the implementation change it passed in the full suite as `ok 402`.
