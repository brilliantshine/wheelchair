The settings page task should use `settings.monoModelNames` for model-name styling and `settings.keyPrompt` for the key prompt, including `signinHint`; the page was not edited here. The lead was notified.

Every grep hit below is the allowed `codex` directory component in `path.join(hub.root, 'codex', 'model.sh')`: balancer.js lines 81, 93, 99; sessions.js lines 107, 109, 120; settings.js line 423. No server grep was requested; its graph-harness labels remain allowed.

## Choices

- `models.familyCommand` and `models.bareTierSet` name the two model script dispatch flags.
- `settings.scoutAgentTool` selects the special scout wording and its maximum-length check; `stylePreview` selects the existing preview provider.
- `usage.showWarning` preserves the provider-specific warning display; `usage.defaultProblem` preserves the legacy default-account problem rule without coupling it to spend.
- `usage.probeWhileLive` and `usage.tryEveryMachine` name the two independent probe policies.
- `settings.monoModelNames` and `settings.keyPrompt` supply the remaining page presentation values.
