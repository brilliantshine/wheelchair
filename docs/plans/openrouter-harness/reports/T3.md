- `install/test/run.sh`: cover Pi on PATH, its user-prefix symlink, mixed providers, absence, and the OpenRouter default pins.
- `docs/plans/openrouter-harness/reports/T3.md`: record validation and choices.

## Choices

- `install/test/run.sh`: use a symlink for the fallback fixture to verify that the service PATH uses the link directory.
- `install/test/run.sh`: restrict the mixed-provider fixture PATH so the machine's installed Pi cannot supersede its fallback fixture.
