# T10 — OpenRouter test coverage

Added tests for sample delivery and abort, Pi role arguments, busy readiness, usage and login handling, missing transcripts, and restart recovery. No application code changed. No new test failed. The machine validation gate failed twice in unrelated existing tests, so the required full pass remains unverified.

Files changed:
- `machine/test/pi.test.js`
- `machine/test/pi-turns.test.js`
- `viewer/test/app-openrouter-hub.test.js`
- `docs/plans/openrouter-harness/reports/T10.md`

- Pi sample completed entry reaches the starting session
- Pi sample aborted entry delivers no report
- Pi role prompts and reviewer tools are passed in argv
- Pi busy input border is not ready
- Pi usageFrom returns null for any pane
- Pi login status ignores the environment key

- missing Pi transcript does not hold a settled hook
