# R2-2 — a hub-start failure must not hang the node suite

## What changed

- `viewer/test/app-diagram-sensitivity.test.js` — `withHub` now starts the hub inside the
  `try`, so the `finally` runs even when `startServer` throws:

  ```js
  let server;
  try {
    server = await startServer({ stateDir: state, env: { WHEELCHAIR_DIAGRAM_TIMEOUT_MS: '300' } });
    await work({ server, state }, fakes);
  } finally {
    if (server) await server.stop();
    for (const fake of Object.values(fakes)) await fake.stop();
  }
  ```

  Nothing else in the file changed. The fakes are still started before the `try`, as the
  brief specified.

  `/home/collin/projects/personal/wheelchair/viewer/node_modules`, created so the tests
  could run in this worktree. It is already excluded by git (`.git/info/exclude`), so it is
  not in the commit.
