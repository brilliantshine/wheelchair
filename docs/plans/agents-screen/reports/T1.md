# T1 — hub side

## Changes

- `viewer/app/names.js`, `hub.js`, `sessions.js`: choose and serialize thread lead names, backfill on startup, and persist resolved model and effort.
- `viewer/app/agents.js`, `routes.js`: build the public agent tree and machine reachability endpoint, and validate lead names on preferences save.
- `viewer/app/settings.js`, `viewer/pages/settings.js`: persist and edit the names list.
- `viewer/app/API.md`, `viewer/AGENTS.md`: document the API, stored fields, and new modules.
- `viewer/test/app-agents.test.js`, `app-hub.test.js`, `app-settings.test.js`, `app-settings.spec.js`: cover names, tree, startup backfill, session records, settings and browser editing.

## Choices

- `viewer/app/names.js`: placed pure name choice in its own module.
- `viewer/app/agents.js`: placed tree construction and machine status assembly together in a new module.
- `viewer/pages/settings.js`: used a Save button for the multiline names field, matching other typed settings.
