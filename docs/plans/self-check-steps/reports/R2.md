# R2 — check note separators

## Changes

- `viewer/app/card.js`: the `check` step note rule now rejects CR, LF, U+2028, U+2029, and U+0085. U+2028 and U+2029 are written as `\\u2028` and `\\u2029` escapes because literal instances are invalid inside a JavaScript regex literal.
- `viewer/test/app-check-card.test.js`: added refused notes containing U+2028 and U+2029 immediately after the existing newline case.
