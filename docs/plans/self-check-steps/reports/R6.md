# R6 — lead.md: Fix-it-now press rules (wording)

Remediation of verification attempt 3. Wording only, in `protocol/app/lead.md`, step 10
(`### 10. Check it yourself`), the **Posting.** and **Restart.** paragraphs.

## Changed files

- `protocol/app/lead.md`
  - **Posting.** A `done` now counts as a newer version only when its `head` differs from the
    current check card's; a retried `done` at the same head does not.
  - **Restart.** The press is skipped when the context has a `done` card with a different
    `head`, or a `stub` card created after the press (fixed, or turned into a follow-up thread
    because the pull request was merged), or when the local branch has commits past that
    card's `head`.
- `docs/plans/self-check-steps/reports/R6.md` (this report)

No other file changed. `protocol/app/sub-lead.md` and `protocol/app/worker.md` are untouched.
