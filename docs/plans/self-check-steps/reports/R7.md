# R7 report — check card shows `update` as plain text

Remediation of verification attempt 4. The check card's `update` was rendered as Markdown, so `/opt/_release_/bin` showed as `/opt/release/bin`. The Spec says card text is set as text.

## Files changed

- `viewer/pages/thread.js`: the `check` case now renders the update with `el('div', 'check-update', card.update)` instead of `prose('check-update', card.update)`.
- `viewer/pages/thread.css`: `.card-check .check-update` gained `white-space: pre-wrap;` (kept `overflow-wrap: anywhere`). The unused `.card-check .check-update code { ... }` rule is deleted.
- `viewer/test/app-check-card.spec.js`: new test in the size loop, "the update is plain text: backticks and asterisks show literally". It posts an update of ``Run `cd /opt/_release_/bin` then **merge** it.``, asserts `.check-update` has that exact text, and asserts the card has no `code` or `strong` element. The existing long-path wrap test is unchanged.
- `docs/plans/self-check-steps/reports/R7.md`: this report.
