# T1 — discovery and stub additions

Changed files:
- `viewer/app/peers.js`: candidate helper and discovery fields.
- `viewer/app/card.js`: addition field and cross-field validation.
- `viewer/app/cards.js`: locked target checks and context append.
- `viewer/test/app-lead-list.test.js`, `viewer/test/app-hub.test.js`: discovery, validation, append and refusal coverage.
- `docs/plans/stub-dedupe/reports/T1.md`: this report.

The first focused run expected HTTP 202 for a duplicate note; the existing route returns 200 when the card has `duplicate: true`. The second focused run checked the error category instead of its `detail`. The first full run also had a quiet-session timing failure while both suites ran concurrently. The final runs passed sequentially.
