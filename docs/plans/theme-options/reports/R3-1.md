# R3-1 report

## Changes

- `viewer/pages/thread.css`: `.opt:hover:not(:disabled)` (line 138) and `a.sent-file:hover` (line 348) now use `--accent-vis` for the border instead of `--accent-line`.
- `viewer/test/theme-rendering.spec.js`: new test "a hovered recommended answer keeps a visible border with a white accent in light mode". It hovers `.opt.lean` in Default Light with `#ffffff` and requires the border to be at least 3:1 against `--panel` and against `--accent-soft` composited on `--panel`.
