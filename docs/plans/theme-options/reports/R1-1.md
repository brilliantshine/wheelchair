# R1-1 report — Agents selected border contrast and theme-rendering stability

## Changes
- `viewer/pages/views.css`: `.agents-entry.selected` border is now `var(--accent-vis)` (was `--accent-line`).
- `viewer/test/theme-rendering.spec.js`:
  - `afterEach` goes to `about:blank`, then `unrouteAll`, both with `.catch`, before `ctx.close()`.
  - `textContrast` returns no value for a detached node and polls until the ratio is finite; callers still assert `>= 4.5`.
  - The white/black accent Agents test asserts the selected entry's border is `>= 3.0:1` against `--panel-3` and `--accent-soft`, for each accent it loops over.

## Regression check (new assertion, CSS not yet fixed)
`npm --prefix viewer run test:browser -- test/theme-rendering.spec.js -g 'working dot'` exited 1, failing in Chromium and Firefox:
