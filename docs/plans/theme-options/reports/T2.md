# T2 — Settings → You Theme editor

## Changes

- `viewer/pages/theme-editor.js` (new): `window.wcThemeEditor.render()` / `discard()`, the visit state, all controls, save / 409 / error handling, `pageshow` repaint (Spec §4). The block's DOM is built once and updated in place.
- `viewer/pages/settings.js`: `theme` block above `background` in `You`; `discard()` when leaving `You` (sidebar, phone Back) and on `pagehide`. Polling and other blocks untouched.
- `viewer/pages/settings.html`: `theme-palette.js` and `theme.js` load synchronously before the stylesheets; `theme-editor.js` loads with `defer`.
- `viewer/pages/settings.css`: Theme styles, 6-column preset grid, 3 columns and stacked rows at `<=700px`, backdrop for the heading over a background image.
- `viewer/test/theme-editor.spec.js` (new): 19 tests covering every case in Spec §7.3, plus saving lock, failed save and a save answered after leaving `You`.

## Choices

- Choosing the value that is already saved does not make a clean editor dirty (`theme-editor.js`).
- Any typing in the hex field makes the editor dirty, so Reset is available for invalid text (`theme-editor.js`).
- Invalid hex text survives mode and preset clicks; a swatch, the color picker or either "Reset to" button clears it (`theme-editor.js`).
- After a 409, other controls still preview; only Save is locked until Reset (`theme-editor.js`).
- Added "Saving…" and "Loading theme…" status text; controls are disabled until theme metadata loads, and a load failure shows the controller's error (`theme-editor.js`).
- The invalid-hex hint reads "Enter a 3- or 6-digit hex color, like #10b981." (`theme-editor.js`).
- The Theme block is at most 936px wide, as in the desktop mockup; it stacks at 700px, not Settings' 899px (`settings.css`).
- Prompt previews needed no CSS change: they already use `--term-bg` with `--ink-2`, and the palette makes `--term-bg` light in light mode. Their light-mode contrast was not separately tested here (`settings.css`).
- The You category's list line ("Your name, writing style, diagrams and background") was left unchanged (`settings.js`).
