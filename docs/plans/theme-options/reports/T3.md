## Changes by file

- `viewer/pages/{agents,doc,features,file,new,picture,terminal,thread,threads}.html`, `viewer/doc.html`: load `theme-palette.js` and `theme.js` synchronously in the head, before any stylesheet. `signin.html` and `index.html` are untouched.
- `viewer/doc.html`: dark fallback tokens added; links use `--accent-text` / `--accent-hi`; the error banner uses the `--bad*` tokens.
- `viewer/pages/app.css`: `--accent-hover`, `--accent-hover-ink`, `--accent-vis`; `color-scheme` rules; logo ink; focus outline and status dots on `--accent-vis`; filled hover pairs; `.lead-chip` on `--accent-text`; spinner reads `--spinner-svg` / `--spinner-svg-reduced` with the old data URLs as fallback.
- `viewer/pages/assistant-popup.css`: hover pairs including the new `.wc-asst-send:hover`; attribution on `--ink-2`; hardcoded human, warn and unread colours replaced with tokens.
- `viewer/pages/thread.css`: visible focus ring on `#composer textarea`, `.own-words textarea` and `.spot-box .spot-text`; non-text accent marks on `--accent-vis`; attribution on `--ink-2`; spot error on `--bad-text`.
- `viewer/pages/views.css`: terminal host fixed dark; non-text accent marks on `--accent-vis`; light-mode trail opacity .75; `.latest-running` on `--accent-text`.
- `viewer/pages/term-view.js`: explicit dark xterm theme; typing cursor fixed at `#d9a441`.
- `viewer/pages/picture-export.js`: the graph PNG canvas colour comes from the graph frame.
- `viewer/pages/agents.js`: the "none" and "not counted" squares read `--good` / `--idle` and repaint on `wc-theme-change`.
- `viewer/pages/{doc,file,background}.css`: audited, no change needed.
- `viewer/test/theme-rendering.spec.js`: new, 12 tests covering Spec §7.4.

## Choices

- Screenshot preset: Forest, because the mockup's green-tinted surfaces are Forest light (`T3-thread-light.png`).
- Agents review squares: only "none" and "not counted" follow theme tokens; the red, orange and yellow steps stay fixed so Default Dark is unchanged (`agents.js`).
- Agents legend now builds its squares with the same `square()` helper so they repaint too (`agents.js`).
- The audit also moved idea dots, lean option border, aside marks, form timeline dots, spot outline and selected agent/deck borders to `--accent-vis` (`thread.css`, `views.css`).
- The assistant pop-up's stopped banner, card and unread dot moved from dark literals to the `--warn*` tokens (`assistant-popup.css`).
- The mockup pin (red with white ring) and the mockup frame's white canvas are left fixed, since they sit on mockup artwork (`thread.css`).
- The spinner keeps its old data URLs as the `var()` fallback (`app.css`).
- Test 10 holds the theme request open so only the cached pre-paint script can colour the page (`theme-rendering.spec.js`).
