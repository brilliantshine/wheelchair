# T1 report

- `viewer/pages/theme-palette.js`: preset palettes, WCAG contrast derivation, color parsing and spinner URLs.
- `viewer/pages/theme.js`: synchronous cached bootstrap, revision-gated hub and storage synchronization, previews and polling.
- `viewer/app/theme.js`: validated revision-controlled theme endpoint with bounded input and atomic settings writes.
- `viewer/app/settings.js`, `viewer/app/routes.js`: preserve theme in normalized settings and dispatch the endpoint.
- `viewer/app/API.md`: document the theme endpoint.
- `viewer/test/theme.test.js`: contrast matrix and isolated API coverage.

The browser wiring and visual surfaces belong to the other tasks, so this isolated controller has no page integration to screenshot in this worktree.

## Choices

- `viewer/app/theme.js`: return a plain `Could not write settings.json` error if the atomic write fails.
