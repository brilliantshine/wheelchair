# Custom accent color and theme options

## What we're building

Let the user replace Wheelchair's default blue accent color with any color they choose, along with additional theme options to personalize how the app looks.

## Why — the problem

Today Wheelchair's accent color is fixed to blue and theme customization is limited. Users who want a different visual look or color scheme across the app cannot tailor it.

## What good looks like

- The user can pick any accent color and see it applied consistently across Wheelchair's pages.
- The user can adjust the agreed theme options from Settings and have their choices persist.

## Not doing

- To be confirmed once the exact theme options are chosen.

## Constraints

- Must work cleanly alongside Wheelchair's existing Settings and Appearance features.
