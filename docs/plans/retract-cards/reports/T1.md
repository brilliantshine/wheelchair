# T1 — hub and CLI card retraction

## Changes

- `viewer/app/card.js`: validate the lead-only hidden retract kind and its one-line note; check retractable targets and refusal order.
- `viewer/app/cards.js`: apply retractions under the thread transaction, cancel waiting sudo requests, preserve withdrawn history, permit a second offer, and pin approvals while replacing only open predecessors.
- `viewer/app/threads.js`: reject withdrawn-card presses before dispatch and unpin approval on accepted Start building.
- `viewer/app/views.js`: omit replaced cards from Needs you.
- `viewer/test/app-hub.test.js`: exercise retractions, target checks, stale presses, offers, approval pins and replacement.
- `viewer/test/app-sudo.test.js`: exercise cancellation, timeout guard, refusal states and later outcomes.

## Validation

The full viewer suite failed one unrelated font route test because this worktree lacks `viewer/node_modules/@fontsource/inter/files/inter-latin-400-normal.woff2`. Installing dependencies would write outside the task ownership boundary. The targeted hub and sudo tests and machine suite passed. The new tests do not independently exercise every requested matrix case: hub-level non-lead posting, delivery-id retry, retracted offer history after reposting, and subsequent terminal delivery after a running sudo outcome remain uncovered.
