# T3 — Hub settings

Implemented the hub side of settings. No Settings page files were changed.

## Changed

- `viewer/app/settings.js`: defaults and 0600 settings persistence integration; validation; per-role model helpers; templates, switch sentences, role-layer composition and cap; style rendering; model options/heads-up; preview request.
- `viewer/app/state.js`: settings path and queued atomic writer.
- `viewer/app/sessions.js`: provider-slot model resolution, Claude effort, permission mode, role layers and recorded template/style versions; one-time live-lead style trailer.
- `viewer/app/chat.js`: strips an ending `[wc:style]` block before marker handling and display.
- `viewer/app/machine-client.js`: optional request timeout, retaining 5 seconds by default; preview uses 75 seconds.
- `viewer/app/routes.js`, `viewer/app/API.md`: Settings JSON routes and their contract.
- `viewer/test/app-settings.test.js`, `viewer/test/app-hub.test.js`, and test helpers: isolated models files for every hub test, fake preview support, and settings/model/style coverage.
