# T2 report — machine service: permission mode, effort, role_layers, /v1/preview

## What changed

- `machine/service.js`
  - `POST /v1/sessions`: new optional `permission_mode` (auto default | bypass), `effort` (low|medium|high|xhigh|max) and `role_layers` (text). All three are validated by `startOptions` before a worktree is created, so a bad value is a 400 with nothing left behind. The mode and effort are recorded on the session.
  - Claude argv: `--permission-mode auto|bypassPermissions`, `--effort <value>` when set. Codex ignores both.
  - `composeRolePrompt(input)` is the one helper for the starting instructions, used by `commandFor` (Claude `--append-system-prompt`) and `start` (Codex first `[wc:role]` message). Pointer is now `Read <ROOT>/protocol/app/<role>.md before responding. It is wheelchair's built-in rules for your role.`; non-empty `role_layers` follow after a blank line; `role_prompt` wins and ignores layers.
  - `readyText`: a bypass session is ready on `bypass permissions on` (an auto session on `auto mode on`, as before; a session with no recorded mode is auto). `checkReady` answers a "Yes, I accept" bypass confirmation with Down, Enter.
  - `POST /v1/preview` (`preview()`): async `spawn`, never the synchronous `command()`; prompt on stdin; `WHEELCHAIR_LANE=1`; timeout on `instance.previewTimeoutMs` (60 s, tests shorten it).
- `machine/test/service.test.js`: fake `claude -p` (stdin saved, env-driven output, stderr, exit code, sleep) and 9 new tests (62 total).
- `machine/API.md`: the three session fields, the pointer text, the bypass confirmation behaviour, and `/v1/preview` with its error bodies (the service's usual `{error}` shape).

## Choices

- `machine/service.js`: put the skip-prompt key in the settings file only for bypass sessions, not auto ones.
- `machine/service.js`: the confirmation matcher is the text `Yes, I accept` (unverified); readiness also refuses a pane showing it.
- `machine/service.js`: a session with no recorded `permission_mode` (recovered, pre-existing) is treated as auto for readiness.
- `machine/service.js`: `role_layers` is trimmed, and whitespace-only counts as empty; a non-string is 400.
- `machine/service.js`: `effort`/`permission_mode` of `null` count as missing; any other invalid value, including `""`, is 400.
- `machine/service.js`: `/v1/preview` validates `model` against `[A-Za-z0-9._:[]-]+` (so it can't be taken as a flag) and requires a non-blank `prompt`.
- `machine/service.js`: the 504 body always says "60 s" even when the injected test timeout is shorter; a timed-out child is killed with SIGKILL.
- `machine/service.js`: `previewTimeoutMs` is an instance field (tests set it directly), not an environment variable.
- `machine/service.js`: a spawn error other than ENOENT is 502 with the error message.
- `machine/test/service.test.js`: the fake `claude -p` saves stdin to `<log>.stdin`.
