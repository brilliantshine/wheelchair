# R1-T1 — Thread cache settling

## Changes

- `viewer/app/state.js`: Added and exported `SETTLE_MS` (2000 ms), records `checkedAt` immediately before `stat`, and reuses a matching cache entry only when its recorded timestamps were settled before that check.
- `viewer/test/app-snapshot.test.js`: Added coverage for an immediate same-size rewrite and for avoiding a second parse after a settled file is read. Existing fixture-based no-reread checks now wait `SETTLE_MS + 200` ms after writing; the chat cache test also waits after its own rewrites.
