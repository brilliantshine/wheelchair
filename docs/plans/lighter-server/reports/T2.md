# T2 report — hidden-tab polling and browser workers

## Changed
- `viewer/pages/nav.js`: new `window.wcPoller(fn, ms)` returning `{ stop() }` (defined before the `#app-nav` early return so every page has it). `refreshNeeds` and `refreshSessions` use it; `refreshAlert` stays a plain 5-minute interval.
- `viewer/pages/threads.js`, `features.js`, `agents.js` (refresh only; the 1 s "now ·" ticker untouched), `thread.js` (chat poll): `setInterval` → `window.wcPoller`.
- `viewer/pages/aside.js`: `closePanel` and `openAside` call `timer.stop()`; `openAside` creates a new poller where it made an interval.
- `viewer/pages/term-view.js`: `start` creates the poller, `stop` (dispose) calls `interval.stop()`.
- `viewer/pages/settings.js`: `usageTimer` is a poller, `syncSection` calls `.stop()`. Sign-in `card.poll` unchanged.
- `viewer/playwright.config.js`: `workers: 2` plus comment.
- `viewer/test/app-hidden-tabs.spec.js` (new): list page (hidden pause, 5-min alert still fires, on-show poll once, next tick a full interval later), chat, aside (pause; closed aside not polled on show), terminal (pause; destroyed terminal not polled on show), sign-in polls while hidden. Visibility simulated by overriding `document.visibilityState`; time moved with Playwright's clock (paused after load so only `runFor` advances it).
- No existing spec needed changes.

## Choices
- `wcPoller` ignores a visibilitychange to hidden (only restarts on visible); a hidden→hidden event does nothing.
- `viewer/pages/nav.js`: helper placed before the `#app-nav` guard so pages without the nav bar still get it.
- Spec freezes the clock with `pauseAt` after initial load, because `clock.install` alone keeps real time running.
