# T1 — Thread snapshot cache

## Changes

- `state.js:cachedThread`, `threadSnapshot`, `allThreads`, `save`, `updateThread`: stat-keyed deep-frozen cache, missing/malformed handling, and write invalidation; mutable reads remain separate.
- `views.js:discoverSlug`, `findSlug`, `features`: separate discovery from persistence and clone a feature record before mutation.
- `hub.js:readSnapshot`, `chat`, `init`, `routes.js:handleThreads`, `chat.js:chat`: preserve locks and provider/slug persistence while using snapshots for unchanged records. `threads.js:threadBySession` clones the returned record for session mutation.
- `app-snapshot.test.js` and `fixtures/thread-list-before.json`: cache, response compatibility, migration, discovery, chat and locking coverage. The list fixture was captured from the original route implementation.
