# T3 — reach card hub side

Implemented the lead-only reach card, post-time checks and display fields, single-thread link creation and press outcomes, Needs you, handoff history and quiet gating. Added API documentation and hub integration tests.

The initial viewer suite run found a stale retract refusal assertion. The sub-lead widened the ownership boundary for that expectation; after updating it, the viewer suite passed.

## Changes

- `viewer/app/card.js`: schema, role, shown and retract rules.
- `viewer/app/cards.js`, `viewer/app/peers.js`: target checks, refusal ordering and stored display fields.
- `viewer/app/threads.js`: reach press, link and queue behavior.
- `viewer/app/views.js`, `viewer/app/handoff.js`: Needs you and handoff behavior.
- `viewer/app/API.md`, `viewer/test/app-reach.test.js`: press documentation and integration coverage.
- `viewer/test/app-hub.test.js`: update the existing retract refusal expectation.
