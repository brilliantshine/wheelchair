Added a real-server lock test for the thread list, lean list, chat, document and ZIP callers in `viewer/test/app-remote-plan.test.js`. Added `viewer/test/helpers/plan-lock-probe.js` to wrap both running hub lock callbacks and record per-thread active counts. Each trigger gets a fresh remote thread; fake machine replies sample on arrival and after 200 ms. The existing snapshot unit test remains intact.

The new lock test passed in both runs. Stopped after the repeated failure as required. Files changed: `viewer/test/app-remote-plan.test.js`, `viewer/test/helpers/plan-lock-probe.js`, and this report.
