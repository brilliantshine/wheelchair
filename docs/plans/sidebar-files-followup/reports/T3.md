# T3 — Picture download and sent-file preview page

## Changed
- `viewer/pages/picture-export.js` (new): graph PNG (clone of the graph viewer SVG; pan/zoom transform removed; viewBox = live group `getBBox()` + 24 px; listed computed styles inlined; `text.label-metric` removed; 2x on the page background; 8192 px cap) and form canvas drawers (timeline, layers, before-after, side-by-side; wrapped text; 2x; 8192 cap); file name per S1; save via blob URL on `<a download>`.
- `viewer/pages/picture.js`, `picture.html`, `picture.css`: Download button. Graph and aside pictures export from `iframe.contentDocument`; forms re-fetch the JSON and draw it; HTML pictures get a plain link to the displayed URL + `&download=1`.
- `viewer/pages/file.html`, `file.js`, `file.css` (new): preview page at `/wheelchair/app/file?thread=&file=`; Markdown via `renderMarkdown` with an http(s)-only link resolver, other types in a `<pre>` via `textContent`; "Too big to preview" past 2 MiB (content-length and actual bytes); Download and back links.
- `viewer/server.js`: `'file'` added to `APP_PAGES` (one line).
- `viewer/AGENTS.md`: file table rows for the two new pieces.
- `viewer/test/app-picture-download.spec.js`, `app-file-preview.spec.js` (new).

## Helper for T4
`file.js` can be loaded on any page (it runs the page code only when `#content` exists) and sets `window.WCFilePreview = { previewable(name, size), href(threadId, storedName), MAX }`. `previewable` applies the S3 extension list and the 2 MiB rule (false for unknown size). T4 must add `<script src="/wheelchair/assets/pages/file.js" defer>` to `thread.html`.

## Choices
- Helper lives in `file.js` as `window.WCFilePreview` (brief left it open); T4 loads that script.
- Form export re-fetches the form JSON from `WCDiagram.source(...)` rather than reading the drawn DOM.
- Graph test checks the PNG by bands (one node per quarter of the width) plus exact dimensions, not per-node pixels.
- Fixed 900 px logical width for form PNGs; styling from the page's CSS variables.
- Non-previewable extensions on the file page show "cannot be previewed" with the Download link.
- Preview tests serve files through the fake machine's `uploadsDir`.
