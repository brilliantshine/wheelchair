# T5 report

- `test-support/macos/check.sh`: checks launchd services, HTTP endpoints, session survival and restart, sensitivity, and Codex preflight; stops its session and removes its own temp directory.
- `test-support/macos/fake-claude` and `fake-tailscale`: provide the offline CLI shims for the job.
- `.github/workflows/macos.yml`: runs the portable suites, installs the services, executes the check, and prints logs on failure.

## Choices

- `check.sh`: use a unique session name and API deletion with a tmux fallback to clean up even after a failed service check.
- `check.sh`: require a new launchd PID before accepting the post-SIGKILL status response, preventing a response from the old process from passing the check.
- `fake-tailscale`: record serve calls in a log under `TMPDIR` and return an empty serve configuration.
