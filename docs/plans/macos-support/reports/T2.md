# T2 report

- `machine/service.js`: locate the macOS Tailscale app CLI when absent from PATH and bypass systemd-run on Darwin.
- `machine/lib/aside-turns.js`: choose the existing /proc backend once at load or a ps backend, with an injectable factory for tests.
- `machine/test/aside-turns.test.js`: exercise ps token matching, failure handling, group signaling, and recovery.

No shell files changed; bash -n and shellcheck are not applicable. macOS execution was unavailable on this Linux machine.

## Choices

- `machine/lib/aside-turns.js`: exported `createProc` with injectable process availability, exec, and signal functions for deterministic tests.
- `machine/service.js`: inspect PATH for an executable before choosing the app-bundle CLI, so an installed CLI that fails still falls back to loopback.
