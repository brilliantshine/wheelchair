# T1 — Kimi usage probe

- `machine/adapters/kimi.js:63` reads the signed-in global account's unexpired credential, requests usage with a bounded timeout and fixed errors, and parses both windows without writing Kimi files.
- `machine/service.js:1907` accepts Kimi usage and passes the test URL override; `machine/API.md:94` documents the route.
- `machine/test/kimi.test.js` verifies parsing, requests, and unchanged files; `machine/test/service.test.js` verifies route readings, failures, redaction, and redirect handling.
