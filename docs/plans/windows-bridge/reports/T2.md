# T2 report

Implemented Windows CLI dispatch and tests in `viewer/app/wc.js` and `viewer/test/wc-win.test.js`; pure parsing and tests in `machine/lib/win-args.js` and `machine/test/win-args.test.js`; Windows project-program detection and filtering in `machine/lib/project-programs.js`, `machine/lib/project-mcp.js` and their tests; and bridge instructions in `protocol/app/worker.md`, `protocol/app/verifier.md` and `README.md`.

The machine suite failed twice on the Kimi login test reporting Kimi Code is not installed. The viewer suite failed twice on two app-slug tests; the second run also had an app-hub failure and a port identification failure. The focused suite passed. No further gate attempts were made.

## Choices

- `win-args.js`: reject repeated timeout options and handles beyond JavaScript's safe integer range to avoid ambiguous or imprecise values.
- `win-args.js`: represent environment entries as key/value pairs, following the screen parser.
