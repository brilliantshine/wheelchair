# A bridge from a Linux Wheelchair to the local Windows side

## What we're building

Wheelchair keeps running on Linux (WSL on a Windows PC, or a separate Linux computer), and
its agents get a smooth way to work on the Windows side: their own Windows copy of the
project, Windows programs and apps they can run and see, and Windows-side tools. Unity is
the first and main use.
