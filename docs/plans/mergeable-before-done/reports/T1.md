# T1 report

Implemented the done-card head schema, the GitHub PR gate and its hub integration outside the thread lock. Added gate tests and updated the done-posting Node and browser fixtures. `app-merged.test.js` uses historical records, not card posts, and needs no update.

Files: `viewer/app/card.js`, `viewer/app/pr-gate.js`, `viewer/app/hub.js`, `viewer/test/app-done-gate.test.js`, `viewer/test/app-thread-list.test.js`, `viewer/test/app-threads.spec.js`.

The full Node suite failed twice, on different tests outside the task; stopped per worker instructions. On the first run the browser suite was also running; its boot-commit test exposed a temporary-clone fixture that copies hub.js but not the new module, so the gate is loaded at done-card handling time. The retry passed that test and the earlier upload test but failed a registration timing assertion. The focused test passed before that module-loading adjustment; the full retry included it and passed the gate tests.
