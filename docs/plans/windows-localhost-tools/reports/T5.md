## Choices
- Switch is a plain checkbox with a `label.check` (existing pattern in settings.js), row layout via inline style since `settings.css` is outside the boundary.
- Switch also shown for non-editable (read-only) entries whose raw `type`/`url` are eligible.
- Store key is `[type, url]` inside a store that is reset whenever the guard (machine, path, gen) changes, rather than a key containing the guard.
- Due keys no longer shown by any line when the debounce fires are dropped from the request.
- Reply entry missing from `status` (or malformed reply) is stored as "Couldn't check: no answer for this tool".
- Marks read from `windows` for names not in `mcpServers` are dropped on read; marks are deleted eagerly when an entry is removed.
- Relative time wording: "just now", "N min ago", "N h ago", "N days ago"; `last.at` accepts ISO string or ms.
- Edit form keeps the switch value locally until Keep changes (Cancel discards it); the list switch applies at once.
