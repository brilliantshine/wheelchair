# T8 report

Changed `viewer/pages/project-tools.js`: an untouched edit switch reads the current card mark and repaints when the card changes; once touched it uses the form value. Rename and hidden-mark handling remain intact.

Changed `viewer/test/app-project-tools.spec.js`: added both card-switch directions, form override and Cancel coverage. The baseline was run before applying the fix (equivalent to temporarily reverting it): both save directions and synchronization failed in both browsers, while Cancel passed in both, because Cancel already behaved correctly. The first full suite failed once due to a test racing the intercepted save request; the retry waits for the request and passed.

Changed `docs/plans/windows-localhost-tools/reports/T8.md`: this report.

## Choices

- `viewer/pages/project-tools.js`: repaint existing status controls after a card switch change, allowing the untouched form control to reflect the live mark.
- `viewer/test/app-project-tools.spec.js`: wait for the intercepted save request before examining its body.
