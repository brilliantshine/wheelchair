# Thread sidebar: project documents and files from agents

## What we're building

A thread's right sidebar becomes the one place for the files agents make. At the top, a
**Project documents** section lists the thread's map, idea, plan and pictures, each easy to
open and to download. Under it, a second section lists extra documents an agent chose to
send you, also easy to open and download.

## Why — the problem

Today the sidebar only links to rendered pages of the map, idea and plan; there is no way
to download them as files. Agents can show you an image, but cannot hand you any other
document (a report, a spreadsheet, a PDF, a log), so anything they make for you stays
buried on the machine.

## What good looks like

- On a thread, the sidebar's top section shows the project documents that exist, and each
  has a way to download it that works on a phone.
- When an agent sends you a document, it shows up in the section below, with its name, and
  you can open or download it.
- On a phone, where there is no right column, the same two sections are reachable from the
  thread.

## Not doing

- Editing documents in the app.
- Changing how you attach files to your own messages.
- Sharing files between threads.

## Constraints

- Must work from a phone browser.
- Files from agents must not be able to run code in the browser (same safety as today's
  attachments).
- Threads can run on another machine than the app, so documents must reach you from there.
