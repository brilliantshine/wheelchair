# T2 report

- `viewer/app/card.js`: declares the lead-only file card and machine-only metadata validation.
- `viewer/app/cards.js`: stores the upload basename with its machine-supplied name and size; cards arrive through the authenticated machine relay, which enables machine validation.
- `viewer/app/documents.js`: shares live eligibility, slug validation, listing and archived existence cache.
- `viewer/app/chat.js`: includes the document list in chat responses.
- `viewer/app/routes.js`: serves live and archived documents and downloads.
- `viewer/app/threads.js`: validates archived document slugs.
- `viewer/AGENTS.md`: documents the new module.
- `viewer/test/app-documents.test.js`: tests cards, live and archived documents, eligibility, downloads and caching.
- `viewer/test/protocol-rules.test.js`: includes the new card kind.
- `protocol/app/cards.md`, `cards-lead.md`, `lead.md`, `sub-lead.md`, `worker.md`: describe the file card and routing documents through the lead.
