# T2 report

Implemented the isolated shared harness and the free smoke suite.

- `test-support/smoke/harness.js`: private origin, clone, state, ports and tmux; seeded live caller; counting proxy; route, tmux, wait and teardown helpers; `--check-live` proof.
- `test-support/smoke/smoke.js`: readiness via the hub and proxy, direct machine start and stop, and cleanup checks.
- `test-support/smoke/run.sh`: checks required tools before starting the suite.

Live caller API: `const h = await createHarness({ mode: 'live', slowOriginSeconds: 8 })`; default mode is `smoke` and default delay is zero. `h.agent({action, ...})` makes an authenticated request as `h.sublead`; `h.callHub(route, method, body)` and `h.callMachine(route, method, body)` return parsed successful JSON and throw on HTTP errors; `h.counts[name]` counts hub-to-machine session starts; `h.statuses` contains machine status responses observed through the proxy. `h.tmux(...args)` returns `spawnSync` output for the private server, `h.waitFor(fn, timeoutMs)` waits for a truthy result, `h.git(...args)` executes git, and `await h.teardown()` stops resources and returns `{privateTmuxGone, runFolderGone}`. The object also exposes `dir`, `paths`, `ports`, `env`, `threadId`, `sublead`, and `token`.

## Choices

- `harness.js`: used the proxy's observed status response while triggering the hub's agents route, since that route checks machine reachability but does not expose the version itself.
- `harness.js`: used `smoke` as the seeded live thread id and `wc-smoke-sub-lead` as its known caller.
- `smoke.js`: checks the private tmux server before deleting its socket directory, preventing a fallback to the default server.
