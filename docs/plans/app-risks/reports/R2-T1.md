# R2-T1: smoke run folder teardown

- `test-support/smoke/harness.js`: match same-UID run processes by exact environment entries or cwd, wait and escalate before cleanup, and report the remaining count. Live mode excludes HOME matching.
- `test-support/smoke/smoke.js`: check folder absence five seconds after teardown and report it with the process count.
- `test-support/test/smoke-harness.test.js`: exercise matching, UID, path boundary, unreadable process and live HOME cases with a fake proc reader.

## Choices

- `harness.js`: after SIGKILL, poll for up to two more seconds so the returned count reflects process exit rather than signal delivery.
- `smoke-harness.test.js`: inject a minimal proc filesystem interface to test matching without creating or removing fixture files.
