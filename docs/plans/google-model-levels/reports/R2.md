# R2 report — gaps G2 and G4

Code commit: b5adbe2c (base 2e6ff11a).

## Changes

- `viewer/pages/settings.js` (G2): new `redrawCell` replaces one model cell in place. A successful save redraws only the saved cell, both right after the PUT (this was `paint(block)`, which also wiped drafts in the same block) and after the GET /settings re-read (was `paint('tiers', 'lead-models')`). `unreadCells` keeps saves whose own re-read was overtaken by a later save, so the later read draws them too. `Saved; the list could not be refreshed` is unchanged.
- `viewer/test/app-settings.spec.js`: new tests for drafts kept in both blocks and for two saves during one pending re-read; the existing re-read test now expects other cells to stay as drawn until their next draw (it was renamed from "redraws the model cells" to "redraws the saved cell").
- `viewer/test/helpers/server.js` (G4): `startServer` sets `WHEELCHAIR_AGY=''` and `WHEELCHAIR_MODELS=<state dir>/models` unless the caller's `env` sets them.
- `viewer/test/pages.spec.js` (G4): its own server starter and `--open` runs get the same two defaults.

## Choices

- `viewer/pages/settings.js`: the redraw straight after the PUT is also limited to the saved cell, not only the redraw after the re-read.
- `viewer/pages/settings.js`: when a second save overtakes the first one's re-read, the later read redraws both saved cells; if that read fails, only the latest cell shows the note, as before.
- `viewer/test/app-settings.spec.js`: changed the existing re-read test, which asserted that another cell was redrawn.
- `viewer/test/pages.spec.js`: treated its local server starter as a test helper that starts a server and applied the defaults there.
- `viewer/test/helpers/server.js`: the default models file is always in the state directory (the helper already makes a temp one when none is given); `WHEELCHAIR_MODELS_CACHE` got no default.
