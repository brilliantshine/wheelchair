# T2 report

- `connectors/agy/machine.js`: asynchronously calls the model launch helper, validates its output, falls back on failure, and passes launch-only model and effort to argv.
- `machine/service.js`: forwards input and session to the launch hook.
- `connectors/README.md`, `machine/API.md`: document the hook and launch fix-up.
- `machine/test/project-mcp-agy.test.js`, `machine/test/agy-launch-service.test.js`, `machine/test/fixtures/agy/model-launch-fake.sh`: cover connector cases, timeout and a fresh service launch with a fake helper and tmux.
- `machine/test/helpers/model-roundtrip.js`: disables host discovery.

The connector-only test seams are `WHEELCHAIR_AGY_MODEL_SCRIPT` and `WHEELCHAIR_AGY_LAUNCH_TIMEOUT_MS`; the default deadline is 15 seconds. The fake never calls agy. A deliberate mutation that ignored both launch extras caused both added tests to fail (4 passed, 2 failed); the implementation was restored before validation.

The picker selects whole suites for `connectors/**`. Those suites are assigned to the lead by the brief, so they were not run here; the targeted commands below passed. No other work remains undone.
