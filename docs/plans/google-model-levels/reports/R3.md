# R3: no viewer test runs the PATH `agy` or touches the real `~/.wheelchair`

## Changed (all under `viewer/test/`)

- `helpers/isolate-models.js` (new): requiring it sets `process.env.WHEELCHAIR_AGY = ''` and `WHEELCHAIR_MODELS` to a fresh temp dir, so in-process hubs, direct `model.sh` calls and spawned servers all inherit them.
- `helpers/server.js`: requires it, which covers every file using a shared helper (`app.js`, `app-machine.js`, `app-views-setup.js`, `app-threads-world.js`, `server.js`).
- `app-balancer.test.js`, `app-project-tools-card.test.js`: require it before their own `WHEELCHAIR_MODELS` line, which still wins. `app-harnesses.test.js` needed no edit (its assignment comes after the helper).
- Require added to the files that load `viewer/app/` without a shared helper: `app-activity`, `app-agents`, `app-asides`, `app-auto-merge`, `app-check-card`, `app-done-gate`, `app-features`, `app-kimi-archive`, `app-kimi-hub`, `app-merged`, `app-mockup-cards`, `app-openrouter-hub`, `app-owner-normalize`, `app-permit`, `app-questions`, `app-report-retry`, `app-slug`, `app-snapshot`, `char-ready`, `char-settings-defaults`, `model-options`, `remediation-r5`, `report-default` (all `.test.js`).
- `app-uploads-archive.test.js`: added an `agy` stub next to its `claude`/`tmux` stubs. Its in-process real `MachineService` ran `agy models` and `agy --version` from PATH without going through `model.sh`, so the two variables could not stop it.

No production code changed. No new tests; the proof below is the check.
