# T2 report

Implemented bounded strict transcript recovery and inline report retries.

- `viewer/app/chat.js`: strict report reads, local fallback and Pi entry detection.
- `viewer/app/machine-client.js`: wall-clock timeout and request cancellation for strict HTTP reads, including dropped responses.
- `viewer/app/sessions.js`: bounded retries, injectable clock and sleep, and existing single-delivery and quiet behavior.
- `viewer/test/app-report-retry.test.js`: retry, absence, quiet, deadlines, local fallback, timeout, dropped connection and dribbling response coverage.
- `viewer/test/app-openrouter-hub.test.js`: update report fixture for the strict client.

## Choices

- `viewer/app/chat.js`: treat a Pi entry as present when its row is an assistant message with the requested ID, even if its text is empty.
- `viewer/app/machine-client.js`: apply the wall timeout to strict pass-through requests generally and cancel pending credential resolution before it can start a late request.
