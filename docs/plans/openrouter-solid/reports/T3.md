# T3 report

- `machine/adapters/pi-guard.js`: static Pi extension that resolves, confines and rewrites paths for read-only tools, refusing missing paths and paths Pi would normalize differently.
- `machine/test/pi-guard.test.js`: fixture tests for all four read tools, path escapes, symlinks, normalization, protocol access and rewritten inputs.
- `test-support/smoke/pi-guard.js`: offline check using the installed Pi extension loader, runner and real read and ls tools; skips when Pi is absent.

## Choices

- `machine/test/pi-guard.test.js`: import extension source as an ESM data URL so Node 20 can test a Pi-style ESM `.js` file in this CommonJS repository.
- `test-support/smoke/pi-guard.js`: use Pi's extension runner for preflight and invoke its real read/ls tools only after approval, without a model or network call.
- Narrow-space fixtures use a symlink to the real path so the test exercises refusal after realpath, rather than only the missing normalized spelling.
