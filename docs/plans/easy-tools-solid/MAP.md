It detects Windows stdio programs, excludes MCP for Unity, and substitutes a proxy keyed by project, name, command and args (`machine/lib/win-tool-wrap.js:7`). The service writes a per-session waiting file and publishes ready or failed with attempt-token protection (`machine/lib/win.js:126`); the proxy polls it, then spawns the Windows program with `WHEELCHAIR_WINDOWS_PROJECT` and `WSLENV`, removing the session token (`machine/lib/win-tool-proxy.js:97`, `machine/lib/win-tool-proxy.js:136`). The parent map describes the original seam (`docs/plans/easy-tools/MAP.md:31`).

Folder server validation requires `start`, so existing HTTP support belongs to project `.mcp.json`: its reader accepts HTTP/SSE URL and headers (`machine/lib/folder-tools.js:18`; `machine/lib/project-mcp.js:77`). Project and shared key stores and folder declared keys already exist; keyed server output is mediated as described in the area map. Project server registration differs by connector: Claude writes replacement and extra entries into a per-session MCP JSON and passes `--mcp-config` (`connectors/claude/machine.js:74`); Codex emits `-c mcp_servers.project_*` overrides, translates HTTP bearer and environment headers, and enforces a size budget (`connectors/codex/machine.js:23`, `connectors/codex/machine.js:52`); Antigravity writes a session plugin `mcp_config.json` (`connectors/agy/machine.js:70`). Gemini is the provider of the `agy` connector, not a separate Gemini CLI connector in this registry (`connectors/agy/manifest.js:5`; `connectors/registry.json:1`).

Codex uses the selected account's `CODEX_HOME` when set, seeds named account homes, and launches with a worktree trust override; reviewers get read-only, ordinary sandboxed sessions workspace-write with network, unrestricted sessions bypass the sandbox (`connectors/codex/machine.js:5`, `connectors/common.js:9`, `machine/service.js:846`, `machine/service.js:866`, `connectors/codex/machine.js:159`). The connector exposes a `codex sandbox` wrapper for other uses (`connectors/codex/machine.js:123`); its presence alone does not prove folder tools are confined.
