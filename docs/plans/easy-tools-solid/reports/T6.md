- machine/lib/folder-tools.js: executable resolution, Windows detection, entry metadata and launcher options.
- machine/service.js: Windows stdio, scripts and HTTP forwarding wiring.
- machine/lib/tool-launch.js: Windows proxy and keyed WSLENV forwarding.
- machine/lib/tool-bridge.js: readiness, project path, keyed environment and timeout accounting.
- connectors/claude/machine.js, connectors/codex/machine.js, connectors/agy/machine.js: folder metadata propagation and Codex Windows environment passthrough.
- machine/test/win-tool-service.test.js: Windows entry, service, readiness, forwarding and environment coverage.

The existing folder-tools test expects the previous entry shape and fails on the newly required false metadata fields. Its file is outside the assigned boundary; the lead was asked to assign or authorize the expectation update. Further coverage of keyed wrapped service launch and sandbox exclusions remains for follow-up.
