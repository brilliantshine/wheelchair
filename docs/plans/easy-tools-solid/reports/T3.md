# T3 report

- `machine/lib/folder-tools.js`: validates HTTP transport configuration and builds HTTP entries; discovery skips executable checks for HTTP.
- `machine/lib/mcp-http.js`: shared HTTP transport, streaming SSE, bounded responses, handshake and session teardown.
- `machine/lib/http-tool-proxy.js`: keyed HTTP forwarding, response checks, initialization gates and session recovery.
- `machine/test/folder-tools.test.js` and `machine/test/http-tool-proxy.test.js`: schema, transport, proxy and handshake coverage.
