# T4 report

Implemented and tested the requested building blocks.

- `machine/lib/win-tool-proxy.js` and its test: optional list cache, held list requests, and exported readiness waiter.
- `machine/lib/project-keys.js` and its test: reserve WSLENV case-insensitively.
- `machine/lib/win-prompt.js` and `machine/test/win-launch.test.js`: recognize loaded Unity folder tools.
- `test-support/run-dir.js` and its test: manage, sweep and clean per-base run directories.
- `connectors/contract.js` and `connectors/README.md`: expose and document the optional sandbox wrapper.

All requested validation passed. Nothing was left undone.

## Choices

- `win-tool-proxy.js`: uncached list requests use the existing call hold timeout and cancellation behavior.
- `test-support/run-dir.js`: record tracked children in every managed root so any dead-owner sweep can clean them.
