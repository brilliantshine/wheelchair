# Router

## Purpose
Wheelchair carries feature ideas through planning, agent sessions, review, and pull requests.

## Directories
- protocol/ — agent role rules, card contracts, graph schema, and plan templates
- viewer/ — authenticated browser application, graph server, and hub orchestration
- machine/ — agent sessions, worktrees, CLI adapters, and machine HTTP service
- sudo-helper/ — separately installed root command approval service and run page
- codex/ — agent model pins and serialized Codex login preflight
- sensitivity/ — renders the diagram preference into harness instructions
- install/ — canonical checkout guard, retired hook removal, and installer fixtures
- test-support/ — isolated test directories, smoke checks, and macOS checks
- docs/ — feature plans, maps, proposals, and known issues

## Important Files
- AGENTS.md — ownership navigation and repository execution boundaries
- README.md — installation and feature workflow
- CONTRIBUTING.md — contribution conventions and validation
- install.sh — installs harness integration and user services from the canonical clone
